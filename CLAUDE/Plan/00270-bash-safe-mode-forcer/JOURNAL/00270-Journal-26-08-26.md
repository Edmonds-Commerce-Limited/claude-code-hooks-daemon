## 12:06 · decision · T3.1 — load-time rejection of `mode: inject`

The handler registry applies YAML options via blind `setattr` inside its
instantiation try-block (handlers/registry.py PASS 2) and offers no option
validation hook. Chosen mechanism: `_mode` is a Python property whose setter
raises ValueError on `inject` — the message names the missing daemon
capability (PreToolUse `updatedInput` is absent from response_schemas.py and
never serialised by hook_result.py) — and on any unknown mode. The registry
catches the raise, logs the message, and the handler is not registered, which
is the load-time rejection the plan requires.
