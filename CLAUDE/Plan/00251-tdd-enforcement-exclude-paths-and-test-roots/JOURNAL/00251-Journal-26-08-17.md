## 14:10 · finding · — — the report's finding A is misdiagnosed

Re-derived all three of the report's findings from source before accepting any,
per the standing discipline that a peer's report is evidence rather than an
oracle. B and C hold exactly as described. **A does not.**

The report frames it as a substring accident: the monorepo path
`…/apps/app/qaConfig/…` "contains the substring `/app/`", with the suggested
remedy being to make the match segment-exact so it stops firing inside
`apps/app/`. Executed against the real code:

```
matches_directory(path, ("/src/", "/app/")):
   True  /workspace/apps/app/qaConfig/PHPStan/Rules/Foo.php
  False  /workspace/apps/foo.php
  False  /workspace/application/foo.php
  False  /workspace/happ/foo.php

PhpTddStrategy on the reported path:
  is_production_source: True
  should_skip         : False
  is_test_file        : False
```

`matches_directory` normalises each pattern to leading AND trailing `/`
(`common.py:22-27`), so it is already effectively segment-bounded — `apps`,
`application` and `happ` all correctly fail to match. The `/app/` hit is a
**correct** match on a directory genuinely named `app`.

So the suggested remedy would change nothing, because `app` already IS an exact
segment. The real defect is a scoping gap — no notion that a QA-tooling dir
inside a source root is not application source — and the fix for finding C
resolves it without touching a heuristic other PHP projects rely on. Recorded as
Non-Goal and Decision 1 so this is not re-litigated later.

This is the second time this week that verifying a report before acting on it
changed the fix rather than merely confirming it. Worth the ten minutes every
time.

## 14:14 · finding · P1 — five byte-identical copies of `_is_excluded`

Checked all six wired handlers before designing the fix, because the obvious
shape ("add the same helper to `tdd_enforcement`") would have made it seven:

```
error_hiding_blocker   defaults prepended, no bool() short-circuit
comment_size           identical
comment_changelog      identical
qa_suppression         identical
security_antipattern   identical
sensitive_content      identical
```

Five are byte-identical; the sixth differs only by prepending its own defaults
and dropping the `bool(patterns)` guard. Every one carries
`getattr(self, "_project_exclude_paths", None)`, a defensive idiom that exists
only because `registry.py:364` injects the attribute after construction.

Hence Phase 1 extracts before Phase 2 adds — otherwise this plan's own
deliverable would be copies seven and eight. It also makes Phase 2 a two-line
change per handler rather than a two-block paste.
