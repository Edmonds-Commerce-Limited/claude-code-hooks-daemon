## 14:40 · finding · — — found because a live probe disagreed with a green test

Building Plan 00373's QA gate, a live probe of the new wrapper against a
scratch root with no plan tree exited 0 and reported the corpus clean. The
unit tests for the same scenario passed while asserting exit 2. Both could
not be right.

Bisected to the entry path. `cmd_plan_qa` called in-process with the root in
its namespace is correct; only the command line loses it:

```
cli --project-root $R plan-qa --sweep   -> 0, "plan tree is clean"
cli plan-qa --sweep --project-root $R   -> 2, "Plan directory does not exist"
```

Cause: 25 subparsers declare their own `--project-root` with `default=None`,
and argparse writes a subparser's defaults into the namespace whether or not
the flag was supplied. So the subparser's `None` overwrote the anchor
`bin/hooks-daemon` passes ahead of the subcommand — and the CLI fell back to
auto-detection, the one behaviour that wrapper explicitly refuses.

## 14:52 · decision · T1.2 — split the dest rather than edit 25 subparsers

The global flag now writes to `global_project_root`, reconciled after parsing
by `apply_global_project_root`. Splitting the dest is what makes the two
layers distinguishable at all: a subcommand-supplied value is now the only
thing that can occupy `project_root`, so "did the caller override the
anchor?" has an answer, and a subcommand value still wins. Twenty-five
subparser edits would each have risked changing a documented per-command
default for no gain.

## 15:05 · finding · T1.3 — two subcommands pre-empted the fix with a cwd default

The source guard written for this plan found `deploy-plan-workflow` and
`agents` declaring `--project-root` with `default=Path.cwd()`. A non-None
default sits in the namespace before reconciliation runs, so those two could
never receive the anchor — the wrapper's forbidden fallback, hard-coded
rather than merely reachable. Both moved to `default=None` with the cwd
fallback resolved inside the command function, where it no longer competes.

The guard itself was wrong on its first run and passed against the real
defect: it bounded each argument block at the first `)`, which lands inside
`Path.cwd()` and cut off the very default being searched for. Bounded at the
dedented `\n    )` instead, it failed and named both offenders.
