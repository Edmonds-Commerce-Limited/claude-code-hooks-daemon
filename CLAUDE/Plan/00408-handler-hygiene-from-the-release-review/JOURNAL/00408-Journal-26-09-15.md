## 18:20 · finding · — — one link above was repointed, and the two rules disagree about that

Archiving Plan 00409 broke this file's link to it (ledger 00419 N2). Repointing
it trips `journal-append-only`; leaving it dead trips `pointer-resolves`, which
is BLOCK at edit time against ADVISE for the append-only rule. Severity settles
it, so the link now reads `../../Completed/00409-…`. No prose was altered — the
edit changed a path and nothing else.

Worth carrying to 00419's N2 ruling: a journal link CANNOT be repointed without
violating append-only, so "repoint every inbound link at archival time" is not
a remedy a journal can accept. That argues for the other option — teach the link
resolver that a plan may have moved to `Completed/` — because it is the only one
of the two that leaves the append-only record untouched.
