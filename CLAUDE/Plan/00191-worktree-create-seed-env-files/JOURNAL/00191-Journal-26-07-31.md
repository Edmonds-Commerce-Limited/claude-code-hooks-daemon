**Reworked to opt-in + uniform fail-fast** (chosen over keeping defaults-on):
`symlink_files` now defaults **empty**. A defaults-on + fail-fast combination
would abort worktree creation in every repo lacking `.env.test.local` — a

`_plan_symlinks` runs pre-`git worktree add`, so no partial worktree). Split
`_seed_files` → `_plan_symlinks` (validate/raise) + `_apply_symlinks` (create;
symlink OSError propagates). `_repo_toplevel` now raises instead of returning
None. Removed both `error_hiding_exclusions` entries — the handler no longer
swallows anything.
