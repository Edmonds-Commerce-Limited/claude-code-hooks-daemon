## REFUTED

R1. Task 6.3: "the only backstop is `CLAUDE_CODE_STOP_HOOK_BLOCK_CAP`, which this loop does not reach."
That variable is not a backstop. remote-docs/code.claude.com/docs/en/hooks.md:2765 describes an 8-consecutive-continuation
cap built into Claude Code, reset each time Claude calls a tool, and says the variable only RAISES that cap.
The backstop is the built-in cap. The plan should name the built-in 8-continuation cap as the backstop, say
the env var merely raises it, and keep the "this loop does not reach it" reasoning, which holds because tool calls reset the count.
