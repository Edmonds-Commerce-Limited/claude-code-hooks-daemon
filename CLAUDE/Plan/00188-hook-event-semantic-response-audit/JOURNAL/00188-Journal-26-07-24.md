## 07:52 · finding · P1 — root-caused the WorktreeCreate bug as a whole class

Triggered by scratch report `untracked/hooks-daemon-worktree-bug.md`:
`isolation: "worktree"` sub-agents fail with
`WorktreeCreate hook returned a path that is not a directory: /workspace/{}`.

Root cause is a **class**, not one bug: Plan 00170 wired every Claude Code hook
event for **structural** completeness (forwarder + schema + settings + dispatch)
with a no-handler default of empty `{}` (fail-open). Correct for most events;
WRONG for events with a mandatory response contract. `WorktreeCreate` must create
the worktree dir and echo its absolute path — `{}` yields the broken
`/workspace/{}`.

Empirically confirmed the empty passthrough:

```
$ echo '{"hook_event_name":"WorktreeCreate","worktree_name":"test-slug","session_id":"abc123"}' | bash .claude/hooks/worktree-create
{}
```

`tests/integration/test_hook_coverage_completeness.py` checks only structural
wiring, never the semantic response contract → that is the enforcement gap.

## 08:05 · finding · P1 — audit complete: exactly ONE genuine break

Probed all 31 forwarders (`scratchpad/event-probe.txt`): most Plan-00170 events
return `{}`; real-feature events (status-line, stop, session-start,
user-prompt-submit, subagent-stop) return real content. WebFetched the
authoritative contracts for the raw-value suspects.

Governing distinction: Claude Code parses a hook's stdout as EITHER a JSON
decision object (`{}` = no decision = SAFE) OR a raw value (`{}` taken literally
= corrupts). Verdicts:

- **WorktreeCreate** — RAW PATH stdout → the ONE genuine break. `{}`→`/workspace/{}`,
  creation fails. Contract: command hook must `git worktree add` and print the
  absolute path; non-zero exit fails creation. Input carries `worktree_id` +
  `requested_path` (+ session_id/cwd/transcript_path).
- **UserPromptExpansion**, **Elicitation** — SAFE-SUBTLE: `{}` is valid JSON =
  "no decision" so today it is a no-op, but a future client handler that emits
  raw text / omits `hookSpecificOutput` is a land-mine.
- **WorktreeRemove**, **ElicitationResult** — genuine no-ops (CC owns the
  side-effect).
- All 24 remaining — decision/observe/context events; `{}` = safe fail-open.

Full matrix in PLAN.md. Phase 1 done. `test_hook_coverage_completeness.py` only
checks structural wiring, so this semantic break passed every gate — Phase 4 will
add a semantic-contract test.
