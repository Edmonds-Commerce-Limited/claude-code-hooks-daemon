## 13:05 · decision · P1 — design choices

- **Source** = `git -C cwd rev-parse --show-toplevel` (the main working copy
  root), not raw `cwd` — env files live at repo root, cwd may be a subdir.
- **Best-effort**: a copy `OSError` logs a warning and is skipped; the worktree
  and its returned path are never broken by a copy failure (breaking the launch
  would be worse than a missing env file).
- **Fresh-only**: seeding runs inside the existing `if not path.exists()` block
  so an idempotent re-fire never clobbers edits made inside the worktree.
- **Safety**: config entries that are absolute or contain `..` are ignored (no
  traversal out of the worktree). No globbing, no recursive dir copy (YAGNI).
- Public branch — tests use dummy content only (`SEED=<name>`), never real
  secrets.
