## REFUTED (most consequential first)

1. Diff 1, Task 2.1: "every forwarder's relay guard silently falls through to bash". Four forwarders have no relay guard: `.claude/hooks/status-line`, `stop`, `subagent-stop` and `worktree-create` (`grep -L "relay hot path" .claude/hooks/*`). Cause: `RELAY_EXCLUDED_EVENT_FILE_NAMES` (forwarder_generator.py:70, from `events.py:172-186` `relay_eligible`). Fix: say "every relay-eligible forwarder's guard"; status-line, the plan's own subject, is not among them.
2. Diff 2, N523: "Each generated forwarder's relay guard requires the binary to be executable, so every hook event takes the bash path". Same overbreadth. Four events never have a guard. The conclusion (nothing runs through the relay here) still holds. Fix: "each relay-eligible forwarder's guard".
3. Diff 2, N523: "nothing reports it" is only partly true. `transport_verify.py:491` returns "relay binary missing or not executable", and `transport_toggle.py:289-310` `ensure_relay_binary` reports an absent binary. Both run only at toggle/verify time, not at session or runtime. Fix: "nothing reports it at runtime or session start".
