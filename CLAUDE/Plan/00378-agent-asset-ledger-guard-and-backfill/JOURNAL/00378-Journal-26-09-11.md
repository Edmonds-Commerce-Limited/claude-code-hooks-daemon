## 14:14 · decision · P1 — the guard must be SEEN to fail

Task 1.2 deliberately requires demonstrating the rewritten check failing on a
mutated template before accepting it. This plan exists because a test whose
docstring promised a guarantee was never observed exercising it and shipped as
coverage anyway. Accepting a fresh green run as proof would repeat precisely
that error.

The same reasoning drives Task 2.1's "fail loudly rather than skip if history is
absent". A history-walking check that silently no-ops on a shallow clone is the
identical failure mode one layer out — green, cited as coverage, checking
nothing. CI's `qa` job uses `fetch-depth: 0`, so the capability is there; the
check must refuse to pass when it is not, rather than skip.
