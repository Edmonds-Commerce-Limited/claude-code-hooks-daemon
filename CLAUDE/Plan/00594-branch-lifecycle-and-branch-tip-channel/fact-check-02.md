6. DESIGN §2.7: "The `**/JOURNAL/**` formatter exclusion also goes into `CLAUDE/LLM-INSTALL.md`". This is an intent. `LLM-INSTALL.md` currently has no JOURNAL or formatter-exclusion text (the grep found none). Fine as a to-do, but it is not an existing fact.
