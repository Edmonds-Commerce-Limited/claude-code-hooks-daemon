## 10:52 · finding · — — format-markdown verb route and whitespace-tolerant gate

Class 9 had a second route that the first fix missed. A client QA pipeline ran
the `format-markdown` CLI verb over a directory. Unlike the edit-time
formatter handler, the verb did not skip journal files, so it rewrote two
entry headings on every run. The agent could not commit them (the entry
immutability gate) and could not restore them (`git restore` is human-only).
Fixed on main as Tasks 6.2 and 6.3: the verb skips journal files, and the
gate accepts a whitespace-only change.

The client team asked for a same-day patch release. It was declined on a
relayed request: the quoted owner line asked to raise the issue, not to
release. The coordinator has put the choice to the owner. The interim route
is the guarded unreleased install (`HOOKS_DAEMON_UNSAFE_TRACK_REF`).

The Phase 2 branch passes core, daemon and config unit tests: 7931 passed.
The 2 failures came from the run method. `PYTHONPATH` makes the package
importable, while those venv-diagnosis tests assert it is not. The branch
does not touch them, and they pass on main.
