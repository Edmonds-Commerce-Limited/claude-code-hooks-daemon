>   down the file. A file with no sentinel line above predates this system —
>   its times are local, zone unrecorded (legacy; never rewritten).

> - Bodies may embed fenced logs/diffs/snippets — no size limit — with a
>   one-line takeaway above the fence.
> - End a working session with a `handoff` entry so the next agent's entry

## 17:33 · finding · P2 — the interception point already exists

Read `.claude/ccy/claude-supervise.py` (7,487 lines) rather than assuming the
design:

- `RawInputTap` already buffers forwarded stdin and drains once per tick into
  `TickFacts.human_raw_input`. The hook point is wired.
- `HumanInputLine` already carries an `_ST_SS3` state and
  `_SS3_INTRODUCER = 0x4F`. **Function keys are parsed today** and deliberately
  consumed as non-content — so a hotkey intercepts a sequence the parser
  already recognises rather than teaching it a new one.
- Swallowing a key is proven practice here: the Ctrl+C gate returns `(b"", …)`
  for a lone `0x03`; the Ctrl+Z guard strips `0x1a` outright.
- No `smcup` / `rmcup` / `1049` / `tmux` reference anywhere in the file. The
  rendering half is genuinely new; the input half is an extension.

## 17:33 · decision · T2.3 — the v3.34.1 wedge is the risk to design against

of byte. Task 2.3 exists solely to keep that from reopening, and Task 2.2
covers the realistic trigger — a 3–5 byte sequence split across a `read()`
