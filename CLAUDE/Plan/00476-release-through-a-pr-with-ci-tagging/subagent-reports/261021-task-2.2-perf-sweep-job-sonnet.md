## Disagreements and limits

- `scaled_seconds` (25 files) is NOT marked: those are hang-guard timeouts on
  subprocesses, which loosen with load and are not sweeps. Only
  `scaled_cpu_seconds` asserts a CPU bound. The old N455 failures are all in the
  7 tests above.
- "Required": the workflow cannot say which checks a branch ruleset requires.
  The job is in the same workflow as the other QA jobs, so a red job turns the
  run red. If the ruleset lists required checks by name, `Performance sweeps`
  must be added there by the owner.
- `pyproject.toml` and `.github/` changes classify as the full tier on the next
  push, so the first run exercises the matrix.
- Marked tests also still run in a local whole-suite run, by design.
