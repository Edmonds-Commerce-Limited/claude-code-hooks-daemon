## 11:50 · decision · T1.2 — three decisions the RED test forced

- **HEAD-green is the exact sha.** My first instinct was "latest run green".
  That is precisely the state we were in, and it was wrong.
- **Release-gated plans are recognised by their own status line.** A plan that
  wants the release must say `/release`. The live run immediately showed the
  limit: 00110 IS release-gated and was filed as in flight, because its status
  line said only "In Progress" — the `/release` mention lived in the README
  index row. Decision 2 puts the burden on the plan, so I fixed the plan.
- **Exit 2 is "a human decides", exit 1 is "could not determine", and
  `--accept` rescues only the first.** Acknowledging WIP is not acknowledging
  blindness.

## 12:05 · finding · T3.2 — what the live run taught that the fixtures had not

you, and the fixture now has that spelling too.
