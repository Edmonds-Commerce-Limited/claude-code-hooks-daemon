## 12:03 · finding · —   — secret_file_guard false positive on a grep regex

A dogfooding defect, found during the DBF sweep and not fixed here.

`secret_file_guard` denied a read-only `grep` (R-SECRET-BASH-MENTION) because a regex in the command, `.*bin.*python`, was reported to match the protected glob `.vault-pass*`. That regex names no protected file. Rewording the pattern to `[.]` character classes passed.

Likely class: the Bash-mention matcher treats a regex token from a search command as a glob or path candidate, and lets it match a protected glob even though no real path matches. It needs its own TDD reproduction and its own plan. It is outside Plan 00555's scope.
