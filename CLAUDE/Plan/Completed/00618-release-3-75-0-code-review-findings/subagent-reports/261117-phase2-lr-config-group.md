## Owner decisions

1. N-14, exemptions: with a bad regex in any policy list, ALL `exempt_patterns` are still dropped (as on main). Keeping the valid exempt patterns would allow commands main denies, so it was not done. Extra slow patterns that are themselves valid are now kept (stricter than main).
2. N-12 `(sleep 100)` direction: it moves from an advisory (`(sleep` unbounded) to a DENY (LONG_SLEEP), stricter. The converse, `(sleep 2)`, and `bash -c 'git status'`, move from an advisory to nothing: the guard advises less where main only advised (main never denied these). No deny on main became an allow.
3. N-11 compound commands backgrounded whole (`until ...; do sleep 5; done &`, `( a; b ) &`) stay exempt as on main; reading `sleep 300; (echo x) &` as a whole-exempt is a known miss left for the owner to tighten.
4. `wait`: a `wait` after a backgrounded job is now a slow-command finding (deny), where main gave only the no-timeout advisory.
