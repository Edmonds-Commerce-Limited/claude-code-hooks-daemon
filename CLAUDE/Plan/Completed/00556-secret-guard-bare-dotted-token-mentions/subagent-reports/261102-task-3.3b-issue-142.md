## Change

- `src/claude_code_hooks_daemon/utils/shell_snapshot.py` (new): `default_glob_semantics(command, config_dir=None)`.
  True only if at least one snapshot exists, every one (newest 200, `MAX_SNAPSHOTS_READ`) is readable and records
  `shopt -u globstar` and `shopt -u dotglob` with no `-s`, and the command contains no `shopt` and no `-O`/`+O` word.
  Config dir via the existing `claude_config_dir()`. Verdict cached per directory by directory mtime plus each file's
  mtime.
- `ProtectedFileIndex.glob_matches(..., default_expansion=False)`: a `**` component is read as `*`.
- `secret_file_matching`: both index call sites pass `default_expansion` from a lazy, memoised per-command check.
  Under defaults `**/*` was already nameless-allowed, so `*`, `**` and `**/*` are now consistent.
