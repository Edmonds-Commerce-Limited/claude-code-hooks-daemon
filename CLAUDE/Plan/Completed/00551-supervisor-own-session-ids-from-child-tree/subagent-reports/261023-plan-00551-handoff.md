## GREEN design (what the RED tests expect)

1. `_proc_stat_ppid(stat_line: str) -> int | None`: take the text after the LAST `)` (`rfind`), split it, field 0
   is state, field 1 is ppid; None on no `)`, too few fields, or a non-integer.
2. `resolve_own_session_ids(child_pid: int, proc_root: Path | None = None)`: read `<root>/<n>/stat` for every
   numeric entry (an `OSError` contributes nothing), build a ppid map, walk descendants of `child_pid` (the child
   counts only if its own stat exists), read `environ` ONLY for tree members. Missing root -> empty.
3. New global `_own_session_ids_child_pid: int | None`. `cached_own_session_ids(child_pid: int | None, proc_root=None, *, now=None)`: `None` -> return `frozenset()` without scanning and without exposing the cache;
   a child pid different from the stored one -> clear the cache and last-scan first; then the existing Plan 00182
   throttle (`resolve_own_session_ids(child_pid, proc_root)`).
4. `TickFacts.child_pid: int | None = None` (comment: host-sent; None from a host that predates it); add to both
   JSON functions (`data.get("child_pid")`, int-coerce when not None).
5. `class WorkerChildPid(*, proc_root: Path | None = None, host_pid=os.getppid, own_pid=os.getpid)`: `.pid`
   property; `learn(sent: int | None) -> int | None` (a sent pid wins and is stored; None keeps a stored pid;
   otherwise the legacy-host derivation, stored only on success); `own_session_ids()` returns
   `cached_own_session_ids(self._pid)` looked up through the module at call time (the test monkeypatches it).
   Legacy-host derivation: if `host_pid() == 1` return None; else the children of the host pid (by stat ppid)
   minus `own_pid()`; exactly one -> that pid, otherwise None. Rationale: an old PTY host that hot-reloads a new
   worker sends no `child_pid`; its children are exactly Claude and the worker, so the session keeps working
   until the next ccy relaunch instead of failing to the empty set. It is a tree derivation, never the broad scan.
6. `run_worker(..., child: WorkerChildPid | None = None)`: per tick `child.learn(facts.child_pid)` and
   `own_sessions=cached_own_session_ids(child.pid)`.
7. `main()` worker branch: build one `WorkerChildPid`, pass it to `run_worker` and give
   `_make_worker_plugin_runtime(argv, dir, session_ids=child.own_session_ids)`; make `PluginRuntime`'s
   `session_ids` required (every test already passes it).
8. Host: `TickFacts(..., child_pid=pid)` at 10392; `cached_own_session_ids(pid)` at 10322 and 10456.
9. Two existing tests monkeypatch `cached_own_session_ids` with a zero-arg `lambda:` and call `run_worker`:
   `tests/unit/supervise/test_no_effort_injection.py:245` and `tests/unit/supervise/test_compaction_origin.py:182`
   -- change them to `lambda *a, **k:`.
