## 15:12 · finding · T1.2 — removal put the daemon in DEGRADED MODE

Removed the handler while deliberately leaving `transcript_archiver:` in
`.claude/hooks-daemon.yaml`, to reproduce a client's upgrade rather than
approximate it. The daemon came up degraded: `Unknown handler
'transcript_archiver'`.

This directly contradicted a prediction I had made minutes earlier and had
called verified. I had tested `Config.load_or_default()`, which tolerates
unknown keys — but the runtime check lives in
`src/claude_code_hooks_daemon/config/validator.py`, a different layer. I tested
the layer that was convenient to test and read the green result as an answer to
a question it had never been asked.

The general lesson, which is the same one Plan 00230 recorded: a check that
passes tells you nothing until you know what it looked at.

## 15:20 · decision · T1.3 — retired-handler registry (Decision 3)

Added `RETIRED_HANDLERS` in `constants/handlers.py`, exempted in the validator.
Four pinned tests, one of which asserts a TYPO still fails — typo detection is
the whole reason handler-name validation exists, so the exemption must not
widen into a general escape hatch.

`transcript_archiver` is the first handler this project has ever removed, which
is why the trap was unsprung until today. Any future removal would have hit it.

## 15:45 · finding · T5.1 — the removal broke lint, and the QA exit code hid it

Full QA came back `20/21 PASSED, 1/21 FAILED`. The failure was mine:
removing the archiver's entry from `constants/__init__.py` left `__all__`
unsorted once `RETIRED_HANDLERS` was added (RUF022). Fixed with
`ruff --select RUF022 --fix --unsafe-fixes`; isort-style ordering puts
SCREAMING_CASE ahead of CamelCase, so the new name sorts to the top.

Second-order note for whoever reads this next: I initially reported this QA run
as passing, because the background-task wrapper reported exit code 0 while the
captured output's first line read `EXIT 1`. The wrapper's status is not the
runner's status. Read the output, not the notification.

That is a better gate than the probe alone: the probe proves the wrapper does
