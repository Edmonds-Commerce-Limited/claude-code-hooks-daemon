   - It is pinned by `test_accepted_residue_a_removal_in_one_checkout_is_unseen_by_another`.
   - Sequence: checkout A removes `feat` with a verdict. The branch is restored. Checkout
     B, which has its own ledger and the SAME shared store, deletes `feat` again on the
     SAME verdict.

     it. **The owner or coordinator should decide whether it is residue or a hole.**
