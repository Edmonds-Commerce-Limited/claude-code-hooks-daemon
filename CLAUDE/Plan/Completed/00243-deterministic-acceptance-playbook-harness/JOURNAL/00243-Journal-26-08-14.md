## 13:35 · finding · P1 — the 49 "failures" were the harness guessing, not the daemon

of that prose and falls back to sending it as Bash when the phrasing differs.
Nothing was wrong with the daemon.

## 14:10 · action · P4 — guard delivered, 8 real defects fixed

`scripts/qa/check_doc_snippets.py` + 29 tests, wired as check 21 in
`run_all.sh` and into `llm_qa.py`. Built TDD: RED confirmed before writing a
line of the implementation.

An audit agent found 7 more broken examples beyond the one fixed by hand.
Every claim was re-verified against the live package before acting, and one
was materially different from the report's framing:

```
1) HookResult(modified_input=...) -> ACCEPTED SILENTLY, has attr: False
2) HookResult('allow') positional -> TypeError
3) AcceptanceTest(test_id=...)    -> TypeError
4) Handler priority default -> 50 (docs said 100); first param handler_id
   abstract methods -> get_acceptance_tests, get_claude_md, handle, matches
5) DaemonServer import -> ImportError (real name is HooksDaemon)
```

Item 1 matters: `HookResult` is a Pydantic model with `extra` unset, so an
unknown keyword is DISCARDED rather than rejected. The documented "modify the
tool call" example therefore produced a handler that looked like it worked and
did nothing — and the capability it advertised does not exist at all.

Measured coverage, rather than claimed: the guard catches 5 of the 8. The 3 it
misses need type inference or intent-reading, and are named in the check's
docstring as out of scope rather than left implicit.

Two bugs in the guard itself were caught by its own tests before commit:
`*args` was being counted as a literal positional argument, and
`from pkg import submodule` was flagged because a submodule is not an
attribute of its package until imported.

Three of this project's own handlers fired on my code while writing it —
`security_antipattern` on `__import__`, `error_hiding_blocker` on an
`except ImportError: pass`, and `lint_on_edit` twice on undefined names. All
three were right; the code is better for each.
