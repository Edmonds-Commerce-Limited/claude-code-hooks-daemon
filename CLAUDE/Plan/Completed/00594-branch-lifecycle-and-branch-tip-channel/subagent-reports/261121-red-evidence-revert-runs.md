# Red evidence by revert runs (gaps from 261121-success-criterion-red-evidence.md)

Repo: worktree `plan-00594-finish`. Evidence only; no tracked file other than this report was changed.

## Method

Script `untracked/scratch/red-run.bash` (untracked) per fix commit F:

1. `git worktree add --detach untracked/scratch/red-<name> F^`.
2. Test file(s) written AS OF F (`git show F:<path>`).
3. Red run: venv `/workspace/untracked/venv-workspace-py313-0d6d49c6/bin/python`, cwd = throwaway worktree,
   `PYTHONPATH=<wt>/src PYTHONDONTWRITEBYTECODE=1`, `-m pytest <files> -q -p no:cacheprovider -o addopts="" -rf --color=no`.
   Each run log begins with `IMPORTED <wt>/src/claude_code_hooks_daemon/__init__.py`, so every run used the throwaway source,
   not the editable install at `/workspace/src`. No conftest guard refused.
4. Test files put back to their F^ content (or deleted if new), `git status --porcelain` checked empty,
   `git checkout --detach F`, green run of the same files, porcelain checked empty again, `git worktree remove`.
   All throwaway worktrees are removed; every clean check was empty.

Logs: `untracked/scratch/red-out/<name>-{red,green}.txt`.

Red rule: an assertion failure, or an ImportError/AttributeError/TypeError on a symbol or parameter the fix added, counts.
When a collection ImportError stopped the run, the other files were re-run alone (suffix `b`) for behavioural red.
