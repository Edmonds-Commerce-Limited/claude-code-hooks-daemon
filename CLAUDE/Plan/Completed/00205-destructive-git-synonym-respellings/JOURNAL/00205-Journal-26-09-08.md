## 00:26 · decision · T1.1 — probed via direct handler instantiation, not the live socket

The plan text says "probe each against the live daemon socket". This
worktree's operating instructions forbid restarting the daemon, and there is
no live worktree-local daemon socket to probe against anyway. Probing
`DestructiveGitHandler().matches(...)` / `.handle(...)` directly exercises
the identical dispatch code the live socket would call — the daemon adds
transport, not decision logic — so this is judged equivalent for THIS
plan's purpose (confirming a decision, not testing daemon plumbing) and is
recorded here as a deliberate substitution, not a silent shortcut.
