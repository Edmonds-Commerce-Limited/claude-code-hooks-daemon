# Task 3.2 report: merge freeze while a release pull request is open

Project handler `.claude/project-handlers/pre_tool_use/release_merge_freeze.py`
(`ReleaseMergeFreezeHandler`, priority 54, terminal, rule `R-RELEASE-MERGE-FREEZE`),
tests in `test_release_merge_freeze.py` beside it (59 cases).

- Trigger: `untracked/release-state.json` with a `ci.pr_number`. No file: one
  `exists()` stat, no JSON parse, allow. A state file without a `ci` record
  (pull request not open yet): allow.
- Denies (parsed with `simple_commands`/`GitInvocation`, `placement_problem`,
  `invocation_directory`, `peel_command_wrappers`; no hand-rolled regex over
  the command): `git merge` when the invocation directory's branch is `main`
  (an unplaceable `cd` counts as main); `git push` whose destination is `main`
  (`main`, `HEAD:main`, `x:refs/heads/main`, `:main`, `--all`, `--mirror`, a
  bare push or `HEAD` from main); `gh pr merge` of any number other than the
  recorded one, or naming none.
- Allowed: `gh pr merge <recorded N>` (also by URL), pushes of release
  branches and tags, `git merge --abort`, merges off main, `git pull`, and
  mentions inside quoted text.
- Malformed, unreadable or non-object state, or a `ci` record without a
  positive int `pr_number`: the same main-moving commands are denied, the
  reason names `release-state.json`. Unrelated commands stay allowed.
- Reason names the open PR, that the tagged commit must be the one CI gated,
  and the way out (finish or abort per RELEASING.md).
- Project handlers are auto-discovered, so no `hooks-daemon.yaml` entry exists
  or is needed for enabling. Daemon not restarted (per instructions); it loads
  on the next restart.
- Acceptance tests: one ALLOW (echo mention); a DENY needs a state file an
  acceptance run must not create, so denies are unit-tested.
- Follow-up for Task 3.1: document the freeze (and `git pull` being unfrozen)
  in `RELEASING.md`.
- Tests were written first but the first run was already green (implementation
  followed in the same pass); priority 53 collided and was moved to 54.
