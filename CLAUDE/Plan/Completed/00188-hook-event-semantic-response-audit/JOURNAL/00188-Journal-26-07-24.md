## 08:42 · finding · P2 — REAL WorktreeCreate payload captured (docs were wrong)

Enabled `payload_capture` (WorktreeCreate/Remove), restarted daemon, launched an
`isolation:"worktree"` Explore agent → reproduced the failure live AND captured
the real payload:

```json
{"session_id": "893e5ac5-...", "transcript_path": "/root/.claude/projects/-workspace/893e5ac5-....jsonl",
 "cwd": "/workspace", "prompt_id": "ee77dac6-620a-4835-a6f8-8216ce5c9232",
 "hook_event_name": "WorktreeCreate", "name": "agent-a780b14327056ac9b"}
```

Key facts (differ from the published docs, which listed `requested_path`/`worktree_id`):

- Claude Code sends **NO path** — it fully delegates path choice to the hook
  (hence the opaque default). The hook MUST choose the path, create the dir, echo
  it (raw stdout; non-zero exit fails creation).
- Only human-ish field is **`name`** (`agent-<id>`, or the Agent-tool `name:` when
  the agent is named). Plus `cwd` (repo root), `prompt_id`, `session_id`.
- Both `.claude/worktrees/` and `untracked/worktrees/` are gitignored;
  `git worktree list` shows only /workspace (the earlier `wf_*` dir was an orphan).

### Design (naming scheme)

Path = `<cwd>/.claude/worktrees/<slug>-<shorthash>/` where
`slug = slugify(name)` (lowercase, non-alnum→`-`, collapse, trim, cap ~40 chars;
fallback `worktree` if empty) and `shorthash = sha1(name|prompt_id|session_id)[:8]`
(md5/sha `usedforsecurity=False`; guarantees uniqueness, honours "hash at the
end"). Branch created same as dir name via `git -C <cwd> worktree add -b <name> <path>`.
Pure naming logic → testable `core/worktree_naming.py`.

### Mechanism

Mirror the `Status` raw-output special-case: `WorktreeCreateHandler.handle()`
runs `git worktree add` and carries the abs path; `HookResult.to_json` emits
`{"worktreePath": "<abs>"}`; the `worktree-create` forwarder gets a new
`worktree` response_mode that extracts `.worktreePath` and prints it RAW (command
hooks read stdout as the path). Handler ships **enabled by default** (a client
with no handler would otherwise re-break). WorktreeRemove → handler does
`git worktree remove` + branch cleanup.
