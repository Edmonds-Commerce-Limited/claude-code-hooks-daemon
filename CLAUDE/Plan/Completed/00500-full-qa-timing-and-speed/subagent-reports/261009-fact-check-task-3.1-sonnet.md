# Fact check: Task 3.1 diff, release note 009 (Sonnet)

Scope: the diff at untracked/plan-fact-check/00500-full-qa-timing-and-speed.diff (PLAN.md Task 2.4 tail, Task 2.5, Task 3.1) and release note 009. Task 2.5 describes a removed build and cannot be checked against the tree beyond "no such files"; see row 14.

## REFUTED / not faithful

1. None of the code claims is refuted.
2. Not faithful (provenance, not a number): PLAN.md says the figures were "measured per leg on a loaded host". The hot-spots report says "Before" is the host's own measurement "where I took one, otherwise the last full gate figure". Only the 520 s readers figure is marked as measured on this host; the layer-1 "about 380 s" and the glob-reader "several hundred s" Befores carry no such mark, and the 129.5 s figure is unattributed. Change: say "before: this host or the last gate figure; after: this host".
3. Source-report defect the plan inherits indirectly: the report's Findings say `_rv_wait_secs` "uses the `read -t` builtin always". The code does the opposite: it starts an external `sleep` in the background and kills it from a TERM trap, and uses `read -t` only when no `sleep` is on PATH (scripts/lib/resolve_venv.sh:163-185). The plan's wording ("the watchdog kills its own `sleep`") matches the code, so the plan is right and the report is wrong. Also the report says the layer-1 file is "about 280 s" of the readers, while its own table says about 380 s.
