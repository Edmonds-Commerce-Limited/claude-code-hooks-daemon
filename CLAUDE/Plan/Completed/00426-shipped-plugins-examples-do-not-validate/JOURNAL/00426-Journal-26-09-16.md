## 19:44 · finding · — — the issue's proposed shape is invalid too

Issue #44 asked which of two documented `plugins:` schemas is the real one.
Validating all three candidate shapes against `PluginsConfig` directly says
**neither documented shape loads**:

```
type/class/events            -> Input should be a valid dictionary
paths + plugins[] (no key)   -> plugins.0.event_type: Field required
paths + plugins[] + event_type -> VALID  (only the daemon's own live config)
```

`PluginConfig.event_type` is required with NO default, and is additionally
guarded by the `event_type_must_be_wired` validator. It appears in no shipped
example. Adopting the shape the issue proposed would have swapped one invalid
example for another — so the report's remedy is a hypothesis that measurement
rejected, exactly as the runbook expects a suggested fix to be treated.
