## Follow-up (not blocking, pre-existing, same fail-open class)

`secret_file_matching.path_is_protected` calls `os.path.realpath(file_path)` at line 273, and that raises `ValueError: embedded null byte` for a `file_path` containing NUL. A JSON hook payload can carry `\u0000` in `tool_input.file_path`, so a guard that reaches this call fails open unless something upstream rejects it. This is not N44's empty-path shape. It is related to N45 (a NUL in the word-list path), but it is a different call site. I suggest a new ledger entry, or folding it into N24's structural fail-closed remedy.
