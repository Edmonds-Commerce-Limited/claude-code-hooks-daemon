## 16:20 · decision · P3 — mode overrides level; this settles the EDIT question

Coordinator flagged mid-task that a check's declared `Level` is not what decides
whether it blocks — the surface's *mode* overrides it. Confirmed in this
project's `.claude/hooks-daemon.yaml`:

```
edit_mode: block
commit_gate_mode: warn      # warn-first rollout; flip to block after clean dogfooding
sweep_mode: advise
```

and `sweep_mode` is typed `Literal["advise", "off"]`, so a SWEEP registration
can never block by construction.

This resolves the brief's open question rather than complicating it. I was asked
to think hard about whether the EDIT surface justified extending the handler.
It does, for a reason only visible in the config: **EDIT is the only surface
whose live mode matches the strictness of the existing test.** That test FAILS
the suite; `commit_gate_mode: warn` downgrades every commit finding to
advisory. Commit-gate-only would have shipped a fast loop strictly weaker than
the batch guard it is meant to shorten.

Honest claim to carry forward: under current config this rule DENIES at edit
time and ADVISES at commit time. Not "blocks over-long rows" generally.

## 17:05 · finding · P2 — worktree hazard: pytest was testing the WRONG source

Worth recording because it would silently invalidate any QA claim made from a
worktree. The venv's editable install is a plain `.pth` containing
`/workspace/src`, so a bare `pytest` run inside this worktree imports
`claude_code_hooks_daemon` from the MAIN repo, not from the worktree checkout:

```
$ .../bin/python -c "import claude_code_hooks_daemon as m; print(m.__file__)"
/workspace/src/claude_code_hooks_daemon/__init__.py
```

My first "RED" run was therefore honest by accident (the module genuinely did
not exist anywhere), but a GREEN run would have been meaningless. Fixed by
exporting `PYTHONPATH=<worktree>/src`, which precedes `.pth` entries in
`sys.path`; verified the import then resolves to the worktree.

Every test and QA figure below was produced with that `PYTHONPATH` set.
