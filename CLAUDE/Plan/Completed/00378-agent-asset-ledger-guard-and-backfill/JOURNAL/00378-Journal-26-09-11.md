## 14:14 · decision · P1 — the guard must be SEEN to fail

Task 1.2 deliberately requires demonstrating the rewritten check failing on a
mutated template before accepting it. This plan exists because a test whose
docstring promised a guarantee was never observed exercising it and shipped as
coverage anyway. Accepting a fresh green run as proof would repeat precisely
that error.

The same reasoning drives Task 2.1's "fail loudly rather than skip if history is
absent". A history-walking check that silently no-ops on a shallow clone is the
identical failure mode one layer out — green, cited as coverage, checking
nothing. CI's `qa` job uses `fetch-depth: 0`, so the capability is there; the
check must refuse to pass when it is not, rather than skip.

## 14:52 · action · P1,P2,P3 — all three phases delivered, each guard watched failing

`AgentAssetSpec` gained a declared `md5`; `ledger()` reads it instead of
re-deriving it from the file. `classify_agent` deliberately still compares
against the actual file, so a stale declaration cannot break a live install —
the declaration's only job is to be checked, which is what makes it a witness
rather than a second source of truth.

The check moved out of the test and into `unpinned_agents()`, so the failure
path could be exercised through the same function QA calls rather than an
inline comparison that can drift from it.

**Every guard was observed failing before being accepted.** Dropping the
docs-qa backfill entry:

```

ledger … Add each digest to that agent's historic_versions:

That second run was not ceremony. `test_every_past_revision_classifies_as_refreshable`
loops over revisions and `continue`s past the current one — if the loop had
been empty it would have passed while asserting nothing, which is this plan's
own defect in a new costume. Watching it fail is what proves it iterates.

**A third check earns its place beyond completeness.** Completeness is a means;
the property that matters is that a ledgered revision classifies `OUTDATED`
rather than `CUSTOMISED`. Asserting only that a digest is present would not
catch a classifier that stopped consulting the ledger at all, so the test
deploys each historical blob into a temp project and classifies it for real.

Backfilled all four digests, labelled by the commit that shipped them so the
claim stays checkable. The independent prototype
(`untracked/scratch/n10_ledger_audit.py`), written before any of this code
existed, now reports `Unledgered revisions: 0` — a second opinion that shares
no code with the test.
