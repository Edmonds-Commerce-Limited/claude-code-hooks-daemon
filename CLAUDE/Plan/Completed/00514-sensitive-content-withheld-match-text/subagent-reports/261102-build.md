## Implementation

`src/claude_code_hooks_daemon/handlers/pre_tool_use/sensitive_content.py`:

- `_find_public_pattern_match` carries a match offset, not the text.
- Each `_Haystack` has a public-safe `location`, fixed at construction and never derived from the text. A command line or a path can itself carry the match.
- Write/Edit body: the file path and the line. The path haystack: "the file path of this write". Git: the field (commit message, tag, branch, author identity, merge message). `gh`: the inline body or title, or the message-file path. Staged content: the path.
- A location that itself matches a pattern is replaced by a generic label.
- Rule text, module docstring, `get_claude_md` and the acceptance-test description updated.
