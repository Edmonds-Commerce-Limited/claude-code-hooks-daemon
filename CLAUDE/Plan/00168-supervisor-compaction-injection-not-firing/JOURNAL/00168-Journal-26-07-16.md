## 09:45 · decision · P4 — icon/design revised per user, then shipped

User feedback changed the design: (1) shield is wrong — it's not defence, the
supervisor OVERSEES/directs → use a **top hat** 🎩 (Fat Controller); (2) prefer a
SINGLE icon, encode state via **background colour** (ANSI bg DOES render behind a
glyph, unlike fg which can't tint an emoji); (3) **on by default**; (4) **memoise**
— the (pid, armed) identity is immutable for the session, so avoid re-reading the
multi-kB `/proc/<pid>/cmdline` every ~1-2s render.

Reworked the agent's handler accordingly: single 🎩 with `\033[42m`/`\033[43m`/
`\033[48;5;208m` background (green/yellow/orange); added a NOT_CONFIGURED state
that renders NOTHING (makes on-by-default safe for non-ccy clients); memoised
(pid, armed) with a per-render `os.kill` liveness fast path (a crash still flips
to orange, cache dropped + re-resolved). 22 tests, 100% coverage, black/ruff/mypy
clean, full unit suite green.

Live dogfood via the real `.claude/hooks/status-line` wrapper: emitted segment is
`\033[42m 🎩 \033[0m`, positioned right after the context `◔ 20.0%` and before the
clock — adjacent to the context section, green because the supervisor is armed.
Committed (feature + regenerated HOOKS-DAEMON.md).
