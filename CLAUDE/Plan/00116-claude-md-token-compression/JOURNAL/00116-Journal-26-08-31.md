## 2026-08-31 — Phase 3 foundation + reference migration, Phase 4 reset wiring

- Wired `DisclosureTracker` into the daemon by mirroring `HandlerHistory`'s
  existing access pattern: `DaemonDataLayer.disclosure` property, backed by a
  `DisclosureTracker()` built in `__init__` and rebuilt in `.reset()`
  (ce80f38d). Any handler now reaches per-agent rule disclosure state via
  `get_data_layer().disclosure`.
- Migrated `destructive_git` (the designated reference handler) off its old
  `_get_block_count`-driven terse/standard/verbose ladder onto
  `get_rules()` (9 `Rule` objects, one per pre-declared `RuleID`) +
  verbose-first/terse-after keyed by `(transcript_path, rule_id)` via the new
  tracker (f491c717). `matches()`/`_match_reason()` and the underlying
  pattern list are untouched — zero matching-behaviour change, asserted by
  the unchanged `matches()` test suite staying green. Every deny now leads
  with `BLOCKED [R-...]`. An event with no `transcript_path` fails toward
  verbose on every fire (unknown state -> more info, per the plan's risk
  table) rather than sharing a fallback bucket across agents.
- Found and fixed a test-isolation trap while migrating: `get_data_layer()`
  is a process-wide singleton, so handler tests that call `handle()` directly
  against the real tracker (rather than mocking `get_data_layer`) leak
  `mark_disclosed` state across test methods that reuse the same
  `transcript_path` — a genuine "first fire" test read as "already
  disclosed" depending on run order. Fixed with an autouse
  `reset_data_layer()` fixture in the test module; documented as a named
  pitfall in `MIGRATION-PATTERN.md` for the parallel fan-out agents.
- Phase 4 reset wiring: added `DisclosureResetPreCompactHandler` and
  `DisclosureResetSessionStartHandler` (both enabled by default,
  non-terminal) that call `get_data_layer().disclosure.reset(transcript_path)`
  for the firing agent on PreCompact and on every SessionStart (Decision E —
  the hook payload does not reliably distinguish "clear" from an ordinary
  SessionStart, so resetting on every SessionStart is the accepted cheap
  cost) (30e856c5). A missing `transcript_path` is a safe no-op in both.
- Wrote `MIGRATION-PATTERN.md`: the exact recipe (imports, `get_rules()`
  shape, tracker access, `RuleFormatter` calls, test shapes, the
  singleton-leak pitfall) for the ~20 remaining Task 3.1 handler migrations,
  so they can proceed mechanically in parallel.
- Full targeted QA green throughout (handlers/constants/config/core test
  trees, mypy --strict, ruff, black); daemon restart verification pending
