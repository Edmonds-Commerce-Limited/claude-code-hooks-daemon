## Notes worth acting on

- Claim 17 (Task 1.2 "clear call, not raised with the owner") sits in tension with the research report section 5. The report says auto-writing `idleCompaction` "would be an owner decision". The `_enforce_settings_sync` docstring (optimal_config_checker.py, lines 496-503) records the Plan 00466 N47 policy against second-guessing owner settings. The plan's design is defensible (it writes only when the key is absent, and the default is already `true`, so the write changes nothing in effect). The plan should say so, or note that the owner delegated the decision.
- Claim 7: `FORCE_PROMPT_CACHING_5M` disables idle compaction only indirectly, because idle compaction needs the 1h cache TTL. The plan lists it flatly alongside the direct switches.
- Claim 10: the 2.1.314 extension to Bedrock, Vertex, Foundry and LLM gateways applies only "once the one-hour prompt cache is on". The plan omits that condition.
