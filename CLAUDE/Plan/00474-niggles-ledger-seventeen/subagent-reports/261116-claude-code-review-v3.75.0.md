No change in range contradicts or extends a pinned fact (G1-G5). Checked for: CLAUDE.md discovery and imports, `.claude/rules/` and `paths`, AGENTS.md, `claudeMdExcludes`, and what survives `/compact`. None of these is mentioned. Nearest items:

- 2.1.325 "Changed Claude's instructions to keep files you'll want out of its temporary scratchpad folder, which can be cleared". This is Claude's own system prompt, not instruction-file loading. No fact id applies.
- 2.1.323 "Fixed running `/compact` again, or after a command such as `/context`, summarizing away a message that Claude had not answered yet". This is compaction behaviour, not instruction survival (G5-01 to G5-03 are unaffected).
- 2.1.325 "Fixed the tip after a slow worktree creation suggesting a `sparsePaths` list without `.claude`, which left worktrees without your project settings and rules". This is a tip fix. Nothing in G3 changes.
- 2.1.325 "Changed `CLAUDE_CODE_MAX_CONTEXT_TOKENS` to also set the context window of unrecognized model IDs that start with `claude-`". 2.1.323 "Changed the context window assumed for a model ID that Claude Code doesn't recognize from 200K to 1M". Both touch window size. G4-05's on-demand file limit depends on the window (40,000 characters at 200K, higher at 1M). An unrecognized model now gets the larger limit. This extends G4-05's window conditions, but the memory page is the anchor and it was not re-checked here. Footprint code uses the 200K minimum: `src/claude_code_hooks_daemon/docs_qa/footprint.py:56`. The 200K minimum stays conservative and correct.
