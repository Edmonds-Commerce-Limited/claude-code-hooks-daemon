1. N418 residual: "a lambda or an alias of a launcher handed as the callback is may-run, not a run". Run against the current code with the repo .venv:
   - `run = subprocess.run; def d(cb,c): cb(c); d(run,'pytest')` ranks the literal as RUN.
   - `d(lambda c: subprocess.run(c), 'pytest')` ranks it as RUN.
   - Cause: `_value_rank` calls `_launcher_named`, which walks the whole expression and finds the launcher name (subprocess_full_qa_blocker.py:4377).
   - Only a lambda or alias that does not name a launcher is may-run (line 4379-4380).
   - Correction: say that an alias or lambda that names a launcher is a run, and that only other lambdas, and aliases the script does not bind to a launcher, are may-run. This also weakens "every residual above errs toward may-run": these two are runs, which is correct.
