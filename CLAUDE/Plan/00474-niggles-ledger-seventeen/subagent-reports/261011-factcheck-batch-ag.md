## REFUTED (most consequential first)

1. PLAN.md Niggles list: "99 more rows are fixed ... (✅; 100 carry ✅, two of them already counted above)". The status column holds 101 rows with ✅ (checked twice, with grep -c over the extracted last column), 2 of them also ⬜ Owner decision. The "99 more" is right; "100 carry ✅" should read "101 carry ✅". Total check: 3 open + 14 owner + 99 more ✅ + 1 pure 🚫 + 3 🔄 + 1 pure 🟡 + 1 ↩️ = 122.
2. subagent-reports/261011-batch-ag-sonnet.md: "New class TestStringsOnlyCountAtAProcess (23 cases)". The class has 29 parametrised cases: 8 (\_PYTHON_DATA_CALLS) + 14 (\_PYTHON_ROUTES_TO_A_PROCESS) + 4 (unseen) + 3 single tests. Correct to 29.
3. N418 mechanism: "ranks a script function by EVERY function value it is ever handed". The code (`_CallRanker.__init__`, `_leaf`, `rank`) does not do that. A script helper's rank comes from the calls in its own body: `handler(payload)` or `fn(*a)` calls an unreadable parameter, so it is may-run (rank 1), whichever value a call site passes. Only script functions handed on are propagated (`callers`/`_function_arguments`). The behaviour is real (cases 5 and 7 give unseen on HEAD, deny on main) but the cause is "the helper's body calls its parameter". Reword it, and the suggested fix ("rank by the value actually passed") still holds.
