## REFUTED (most consequential first)

**R1. N420 Status: "FailOpenBoundaries.md covers handler-level boundaries, not this one."** (NIGGLES.md N420)
`CLAUDE/Security/FailOpenBoundaries.md` line 66-68 says the sweep covered `core/chain.py`, `core/front_controller.py`, `daemon/controller.py`, `relay/hooks_relay.rs` and `init.sh`. Line 158 says "All eleven `init.sh` candidates". Lines 106-118 are a whole section on `init.sh`'s CI passthrough and start-under-way denial. So the page does cover this boundary. Change: say it covers `init.sh` too, and cite it as the inventory for which states fail open, rather than excluding it.

**R2. N420 Status, and the ARCHITECTURE.md line 790 / README line 126 wording: "CI enforcement" counted as a named setup state where it fails open.**
`.claude/init.sh:1047-1058` shows that when `_HOOKS_DAEMON_CI_ENFORCED == true` the hook hard-denies PreToolUse and blocks Stop and SubagentStop. That is fail closed. `FailOpenBoundaries.md:108-118` says the same: the passthrough that lets calls through is CI without `ci_enabled: true` and a daemon proven down. `ci_enabled: true` denies everything and exempts no recovery command. The word "enforcement" therefore names the closed state. Change: reword to "CI passthrough (CI without `ci_enabled: true`)", and fix the same phrase in README line 126.

**R3. N420 Status: "It fails open only in the named setup states." Also the wording "`.claude/init.sh` fails closed on an installed project".**
That holds only for PreToolUse (when `_pretooluse_deny` is true, `init.sh:679-691, 1090`) and for Stop and SubagentStop (`:1087`). On an installed project with the daemon unreachable, every other event (PostToolUse, UserPromptSubmit and the rest) still goes through `_hooks_daemon_fail_open_json` (`:1093-1095`; `:3205-3221` "Other events"). It also fails open for PreToolUse in the recovery-command carve-out (`:3206-3208`). ARCHITECTURE.md line 791-793 is worded safely ("does NOT open the gate: PreToolUse denies ..., Stop and SubagentStop block"). The N420 status line over-generalises it. Change: "PreToolUse and Stop/SubagentStop fail closed; other events still fail open."

**R4. N423 Evidence: the `decision.log` text quoted in code format.**
The quote is `would-goal-clear: goal clear trigger -> injected '/goal clear'`. `untracked/supervise/decision.log:9069` reads `2026-10-11T15:02:59.204826+00:00 would-goal-clear: goal clear trigger -> would inject /goal clear; injected '/goal clear'`. The time, the label and the fact are right; the quoted string is edited. Change: quote the full line, or drop the code quotes.

**R5. N421 Status, Review: "probed about 50 shapes and found no new bypass."**
There is no batch AO review report in `subagent-reports/` (only `261011-batch-ao-sonnet.md` and `261011-batch-am-review-r1-sonnet.md`).
