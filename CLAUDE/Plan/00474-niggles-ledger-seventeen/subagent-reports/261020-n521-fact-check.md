## Partly refuted / caveats first

1. C5 (incomplete, not wrong): the string-sequence entry is not the only carry-over harm. `_consume_esc` (claude-supervise.py:823-833) also takes `[` into CSI (a carried Esc then "\[" opens a CSI that eats following typing up to a final byte 0x40-0x7E) and `O` into SS3 (eats the next letter, e.g. "Ok" loses "k"). The write-up names only P, X, \], ^, \_. Suggest adding "also `[` and `O`".
2. C4 wording: "the box reads empty while it holds text" holds only when the swallowed text is the box's only content. Bytes already in `_buffer` stay; the swallowed bytes are the ones never added. Enter is swallowed too (ground-state Enter handling is skipped in `_ST_STR`), so a submit goes unseen.
