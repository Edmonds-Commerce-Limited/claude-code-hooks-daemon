## REFUTED / qualified

1. N514, "or a four-backtick fence": PARTLY REFUTED. `_COMMENT_OR_FENCE_RE` (footprint.py:71-75) opens on ```` ^(```|~~~) ```` and closes on `^(?P=ticks)[^\n]*$`. A four-backtick opener matches its first three backticks, and a four-backtick closer also matches (three backticks followed by anything). A plain four-backtick fence is therefore preserved, and a comment inside it is NOT stripped. The undercount only happens when the four-backtick fence contains an inner three-backtick line, which closes the match early, so a comment after that line is stripped. Reword to "a four-backtick fence that contains a three-backtick line". The indented-fence half is correct.
