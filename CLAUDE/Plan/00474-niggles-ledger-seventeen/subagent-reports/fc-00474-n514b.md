## Refuted

1. "one after an inner three-backtick line within a four-backtick fence ... is stripped" holds only for an odd count of inner three-backtick lines before the comment. With an inner open and close pair, a following comment is kept, not stripped. Suggested rewording: "...and so is one after a single unpaired inner three-backtick line within a four-backtick fence (such a line closes the match early; the effect alternates with each further inner three-backtick line)". Apply the same change to the STATUS-INDEX row.
