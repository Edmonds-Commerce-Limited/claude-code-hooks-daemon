# PR 250 CI fix (run 45409703038)

Fix commit: `ddd0cbafc` on `plan-00635-host-seat-lane-guard` (pushed, not merged).

## Root causes

1. **Cold-import cycle** (Daemon load; `test_cleanup_after_merge.py::test_the_handler_reaches_no_scratch_archive_module`
   on every handlers shard; through them the coverage combine and the QA gate).
   `utils.teamchat_seat` imports `utils.safe_signal`, which imports the `daemon` package, whose
   `__init__` imports `daemon.server`. Commit `e5fcd12c9` made `server` import `KIT_ENV_VAR` /
   `RUNTIME_ENV_VAR` back from `teamchat_seat`. A fresh interpreter that imports `teamchat_seat`
   before `daemon` (as `handlers.post_tool_use` does via `ci_state_reading` -> `team_role_gate`) dies
   with `ImportError: partially initialized module`. The warm pytest process never saw it.
   Fix: the names now live in the leaf `constants/protocol.py` (`TEAMCHAT_RUNTIME_ENV_VAR`,
   `TEAMCHAT_KIT_ENV_VAR`). `server` imports them from there, and `teamchat_seat` keeps its
   `RUNTIME_ENV_VAR`/`KIT_ENV_VAR` names as aliases. Test first: `TestTheModuleImportsCold` in
   `tests/unit/utils/test_teamchat_seat.py` does a fresh-interpreter import of 4 modules. It failed
   4 of 4 before the fix and passes after.
2. **ruff B009/B010** (QA static on all 3 Pythons): `setattr`/`getattr` with constant attribute names
   in `tests/integration/test_bare_claude_code_environment.py`, `test_team_guidance_declared.py` and
   `tests/unit/handlers/test_team_only_guidance_gate.py`, plus an I001 import order in `daemon/cli.py`.
   Fixed with `ruff check --fix`. Tests are outside the mypy scope (`qa_type_paths` lists
   src/scripts/... only), so plain attribute assignment is acceptable there.
3. **Pinned list rot** (unit-tooling shard):
   `test_handler_enumerating_tests_are_selected::test_no_enumerating_test_is_missing_from_the_list`.
   The new `tests/integration/test_bare_claude_code_environment.py` discovers every handler, so it is
   now listed under the `src/claude_code_hooks_daemon/handlers/*` rule in
   `scripts/qa/changed_tests_map.yaml`.

Coverage (`Couldn't combine ... .coverage.unit-handlers`) and the QA gate failed only because of
the jobs above. Neither needs its own fix.
