# N302 and N314 (Sonnet), branch worktree-n302-n314

## N302

`_runs_inline_code` in `subagent_full_qa_blocker.py` applied `-e/-E/-c/-r/--eval` to any
unrecognised program. It now returns False for an exact-name set of search and text tools:
grep, egrep, fgrep, rg, awk, gawk, mawk, nawk, wc, sort, head, tail, cut, jq (path prefix
stripped). Chosen over an allowlist of known interpreters because that would undo the round-10
decision that an unknown program run with an inline-code flag stays UNSEEN. `awk` is excluded
because its program is a positional argument the handler does not judge either.

Tests (`TestInlineCodeFlagIsNotReadOnSearchAndTextTools`): 20 text-tool shapes return None
(18 were RED before the change); perl, node, ruby, php, `foo -c`, a future-interpreter `--eval`,
`grepx -c` and `echo | perl -e` keep a fail-closed match.
