Key design choices (full rationale in the doc): per-event sockets at
`{untracked}/events{suffix}/{event}.sock` gated on any rung being enabled;
EOF-delimited framing so the relay is a pure byte pump; relay connects BEFORE
reading stdin so connect-fail can exec the bash forwarder with stdin intact;
mid-exchange failures emit fail-open `{}` (bash owns all other error
messaging); config under `daemon.transport` (not top-level — transport has a
natural home); settings.json untouched — the hot path is a generated pure-
builtin guard above `source init.sh`, omitted entirely when disabled so the
deployed forwarder is byte-identical to today; distribution via release
`SHA256SUMS` + plain-`rustc` build-from-source (no cargo, no crates).
Tasks 1.1/1.2 ✅.

## 09:38 · action · P3 — Phase 3 delivered: relay binary, tests, build script

(Container clock reads 09:38 UTC while earlier entries say 10:18 — the agents
have skewed clocks; this entry is appended after them in real order.)

Tasks 3.1–3.3 shipped by the Phase 3 agent:

- `relay/hooks_relay.rs` (~290 lines): std-only, zero crates, no cargo.
  Connects BEFORE reading stdin; on any connect failure execs
  `/bin/bash <fallback> --no-relay` with stdin intact; after connect it is a
  pure byte pump (stdin → socket, `shutdown(SHUT_WR)` as EOF framing,
  response buffered then copied to stdout). One timeout budget spans the
  whole exchange (connect via helper thread + `recv_timeout`, since std's
  `UnixStream::connect` has no timeout; per-op `SO_RCVTIMEO`/`SO_SNDTIMEO`
  armed with the shrinking remainder). Mid-exchange failures emit fail-open
  `{}` + exit 0; diagnostic exit codes 10/11/12 (connect/timeout/IO+oversize)
  only without a fallback / with `--no-fallback`, per design §3.1. Response
  capped at 16 MiB (mirrors `SocketLimit.REQUEST_BUFFER_BYTES`).
- `relay/test_relay.py`: stub Unix-socket server speaking the EOF framing;
  9 cases — happy path, daemon-absent → fallback exec (argv `--no-relay` and
  stdin integrity asserted), connect-fail diagnostic exit 10, timeout →
  `{}`/exit 11, mid-exchange disconnect (4 MiB payload → EPIPE) → `{}`/exit
  12, 2 MiB payload+response round-trip (sha256-verified), oversized
  (16 MiB+1) response → exit 12. **9/9 pass** against the built binary.
- `relay/build.sh`: plain `rustc --edition 2021 -O -C strip=symbols
  -D warnings --target x86_64-unknown-linux-musl` + `strip`, asserts no ELF
  interpreter (static), prints size + sha256. **Built: 570,056 bytes
  stripped** (under the 1 MB ceiling; sha256 f6484c23eb2d…). Output stays in
  git-ignored `untracked/relay-build/` — no binary committed.
