## 10:47 · finding · — — this repo already built this system once, by hand

`contracts/claude-code-hooks/` vendors the Claude Code hooks documentation
with `META.json` recording `docs_url`, `fetch_date`, `docs_sha256`,
`last_audited_claude_code_version` and `refresh_procedure`; a SessionStart
handler (`handlers/session_start/contract_staleness.py`) compares installed
Claude Code against the audited version and advises a refresh;
`docs/guides/HOOK-CONTRACT-REFRESH.md` holds the procedure. Plan 00326 is the
generalisation of that one-off, and two of its scars set the design:

1. A **summarising fetch layer fabricated contract detail** — it invented a
   `permissionDecision: "escalate"` value absent from the raw document (Plan
   00271 audit, recorded in the refresh guide). Persisting `WebFetch` output
   as if it were the source document would institutionalise that failure.
   Raw fetch must be the canonical capture path, and fidelity recorded per
   document.
2. **The advisory rotted.** It is firing right now (installed v2.1.259 vs
   audited v2.1.252) and has simply been skipped in favour of other work. A
   staleness system whose only output is a session-start advisory has a
   demonstrated failure mode in this very repo — hence the in-band staleness
   banner idea: warn at the point of *use*, inside the file being read.

## 10:48 · finding · — — config layer already carries half the mechanism

`documentation.qa.scope_exclude_globs` exists, so excluding a remote tree
from ordinary docs QA is a config change, not a code change.
`documentation.qa.check_modes` gives per-check block/warn/advise control.
`documentation.generated_docs` is a glob→provenance manifest — structurally
the closest existing analogue to a remote-docs registry. And
`documentation.trees` models docs as named trees with distinct contracts
(`agent: CLAUDE`, `human: docs`), which argues for "remote" as a third
registered tree rather than a subdirectory excluded back out of the human
tree's rules.

Reuse points: `utils/markdown_format.py::_split_frontmatter` already parses
YAML frontmatter; `install/relay_deploy.py::_default_fetch` is the house
pattern for network access (https-only, injected `fetch_fn`, digest verified,
never hard-fails).
