## 14:49 · thought · — — an exit code that lied

Recording this for its own sake. The QA background task was reported by the
harness as "exit code 0" while the QA itself had exited 1. The command chained
with `;`, so the reported status belonged to the trailing `tail`, not to
`llm_qa.py`. Taking the harness's exit code at face value would have published
a red tree as verified — 28/29, with two real failures. The habit that caught
it is reading the result the tool produced rather than the status the wrapper
reported.
