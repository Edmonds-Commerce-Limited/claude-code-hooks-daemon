# Issue #147: deny/guidance text hard-codes `bin/hooks-daemon` on client installs

## Existing helper (reused, no second definition)

`claude_code_hooks_daemon/utils/cli_command.py` already owns this. `daemon_cli_command_for_docs(*args)`
returns the project-root-relative wrapper command for the install mode (`bin/hooks-daemon ...` on a
self-install, `.claude/hooks-daemon/bin/hooks-daemon ...` on a client install, client form when
ProjectContext is uninitialised). `daemon_cli_command(*args)` is the absolute runtime twin. I used the
docs form everywhere, because the same text feeds the tracked CLAUDE.md rule table (`Rule.fix`) and the
runtime deny, and a project-root-relative path is runnable from the project root in both.
