Key decisions:

- The reference regex class adds `_` (and `+@~`). DESIGN 3.4's class missed `_`, so a name like `probe_run` failed open.
- A name outside the class has UNKNOWN references and is STUCK.
- The search uses `-a -z`: without `-a`, a binary file match carries no path.
- The rev set is HEAD, the default tip itself and the unmerged branches, plus a working-tree grep.
- An empty rev list, or any failure, is unknown, and an unknown set makes due entries STUCK.
- The filing hint comes from the name only, and a `mv -n` command is printed only for a single file going to a plan folder.
