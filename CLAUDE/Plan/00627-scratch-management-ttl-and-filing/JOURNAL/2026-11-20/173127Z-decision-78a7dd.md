## 17:31 · decision · — — Task 3.0 N3 closed: venv layout

Task 3.0, N3 closed (venv layout). P2 in a venv now covers only what a venv tool writes: the top-level `pyvenv.cfg`, `.gitignore`, `CACHEDIR.TAG`; a `lib64`/`lib32` SYMLINK; the `include`/`Include` tree; files directly in `bin`/`Scripts` whose name matches the venv/ensurepip set (python\*, pip\*, activate\*, Activate.ps1, activate_this.py, deactivate\*, pydoc\*), matched whole; and `lib*/pythonX.Y/site-packages/**` or `Lib/site-packages/**`. `share/` is no longer covered. `_is_venv` now needs an exact interpreter name in the scripts folder and a site-packages path, so `bin/python-notes.txt`, `bin/pythonista` and `bin/python/x` are not interpreters. Decision: a console script pip installs later has an arbitrary name and is uncovered, so a real venv with installed tools reads UNCERTAIN; that over-protects only and the re-review accepted it. Three existing fixtures used `lib/site.py` or `lib/python3.13/site.py`, which a real venv never holds; they now use site-packages.
