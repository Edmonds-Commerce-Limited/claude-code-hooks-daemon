Task 3.6 built (units 2-4): `scratch_archive_expire.py` (complete_records, keep, expire_due) and `scratch_archive_restore.py` (restore, leftover_staging), plus `rename_noreplace_between` in claim.

Decisions:

- Completeness is one helper (`complete_records`): no torn index, at least one record, every record of the id agrees on SHA-256 and size, no `expired` event. Keep and restore refuse an incomplete id; `records_of` returns every record of a batch id (`IndexRead.by_id` returns only the first).
- Effective expiry is the max over all records of `expires_at` and `packed_at + retention[verdict]`, and over all keeps' `until`. A null `expires_at`, a verdict with no retention or an unparseable instant holds. One keep on any batch entry holds the whole archive.
- Expiry refuses the run on a torn index or events tail; any exception from the clock or the caller's `still_referenced` predicate (required, no default; git facts arrive in 3.8) holds that id. Order: lstat regular → `expired` event → lstat same inode → unlink → fsync. A rerun finishes an id with an event whose archive is still present. `audit()` no longer lists an expired id as missing.
- Keep tolerates a torn events tail (its append is the repair; expiry refuses until then). Reasons are whitespace-collapsed and casefolded for the repeat check; bound `until <= now + max_hours`; must extend the effective expiry; capped per archive.
- Restore does every check before staging (lock, complete, entry selection for a batch, plain name from the record, destination absent by lstat, same device, size and SHA-256 through the descriptor later fed to tar, headers: dir/file/symlink only, `./` names with no empty/./.. component, no duplicates, nothing beneath a symlink member). Layout from headers must match the record (directory: counts by kind and skips; member: only `./.sweeping-*`, kind matches). The P6 `name/...` layout is refused here; Task 3.7 must add it with a round-trip test.
- Staging is `.restoring-<random>` in the store; tar extracts with `--keep-old-files --no-same-owner --preserve-permissions`; the staged tree is verified (member set + `tar --compare`); one no-replace rename moves it. tar leaves its working directory's mode alone, so the archived root mode is applied by descriptor after the move. A failure cleans staging through descriptors on the inode it created (a second, small recursive remover: the remove module's walk needs an archive proof, which a partial extraction cannot give). A crash leaves staging, reported by `leftover_staging`, never deleted by a later run; Task 3.8 should decide whether the sweep reports or reclaims it.

New deletion surfaces: `scratch_archive_expire._unlink_expired` (unlink); `scratch_archive_restore._clean_staging` (rmdir), `_empty_dir` (unlink, rmdir). New move: `scratch_archive_restore._move` → `rename_noreplace_between`. All pinned.
