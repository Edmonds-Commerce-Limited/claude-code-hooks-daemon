## F1 (confirmed by probe): a narrower `--root` hides every protection that comes from outside that root

- **Where:**
  - `core/untracked_roots.py:101-167` accepts a root at any depth under `untracked/` that is not inside a repository.
  - `core/scratch_sweep.py:261-282` and `_with_dependencies` see only the entries inside the root.
  - `core/scratch_archive_facts.py:41-48`: `entry_in_use` only checks a process's working directory at or below `<root>/<name>`.
- **What it allows:** I ran a fixture project with the CLI's own seams, using the `wall_clock` seam set 3 days ahead.
  - `lend/lender/` is a standalone repository. A sibling, `borrower`, has `objects/info/alternates` pointing into it.
  - At the default root, `lend` is PROTECTED.
  - `scratch-sweep --root untracked/scratch/lend` makes `lender` DISPOSABLE. `--apply` ended with outcome `archived` and the tree removed. `git fsck` in `borrower` then fails with "unable to normalize alternate object path".
  - For a real `git clone --shared` the borrower's history is unreadable at once. It is lost for good when a later run at that same sub-root expires the 12h DISPOSABLE archive, because expiry only re-checks claims and tracked-file references.
  - Same class, also probed: a process whose working directory is `untracked/scratch/cwdd` makes `cwdd` LIVE at the default root. With `--root untracked/scratch/cwdd`, its child `c2` is UNCERTAIN, so it can be acted on.
  - Not a bypass: a tracked file naming the parent still gives the child REFERENCED at the sub-root, and apply did not act on it.
- **Threat-model test:** in scope. `--root <dir>` is a documented flag a careless agent would type ("sweep just my run dir"). It is ordinary text, fully visible, and not a parser-defeating shape.
- **Class:** a protecting fact (a git pointer, a working directory, a background command) whose source lies outside the sweep root while its target lies inside. Every cross-entry check only ever sees sources inside the root.
- **Why the tests miss it:** the N1, F2 and liveness tests build the borrower and the lender as siblings in one root, and the sub-root tests (N4) test reference spelling only.
- **Inferred, not probed:** the default root has the same blind spot for a borrower anywhere outside `untracked/scratch`, for example `untracked/repos/x` cloned with `--reference` or `--shared` from a scratch repository.
- **Detector hypothesis:** for every protection rule, test whether its source scan is bounded by the sweep root. If it is, add a test with the source one level above the root. This flags every pointer and liveness rule; few false positives.
- **Fix before `--apply`:** take one of these:
  - restrict `--apply` (and expiry) to roots that are a first-level `untracked/<key>` directory;
  - scan pointers, working directories and background commands across the whole project and `untracked/`, including repositories under `untracked/repos`.

## Low notes

- **Restore:** `_scratch_restore` restores into whatever `--root` is named now, using the basename only, and never checks the record's original path or checkout. No overwrite is possible (no-replace rename), so no data loss.
- **Malformed TTL:** a value like `scratch: "7 days"` silently becomes the 24h default, with only a log warning. This is design-accepted, but it fails toward a shorter TTL.
