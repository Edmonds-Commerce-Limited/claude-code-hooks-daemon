## Left

Advisor guidance to carry into this work:

- **Define "complete" once**, in one helper used by expiry, keep and restore:

  - the index has no torn tail;
  - the record exists;
  - every record of the id agrees on SHA-256 and size;
  - there is no `expired` event for the id.

  Keep and restore refuse an expired id.

- **Expiry** may delete an id only after every record of it passes, and an exception from the clock or the predicate holds it.

  - Refuse the whole run on a torn index or torn events tail.
  - Use aware instants only. One keep on any batch entry holds the whole archive.
  - Order: lstat (regular, not a link) → `expired` event → lstat again → unlink → fsync dir.
  - A rerun finishes an id that has an `expired` event but whose file is still present. Test that crash.

- **Keep**:

  - Normalise reasons with `" ".join(reason.split()).casefold()`. Avoid `.replace`, `.remove` and `.rename` spellings anywhere in a `scratch_archive*.py` module: the pin test's AST scan flags them as deletion surfaces.
  - Bound: `until <= now + max_hours`.
  - It must extend the effective expiry (the max of `expires_at` and the keeps' `until`). A null `expires_at` cannot be extended, so refuse it.
  - Cap the number of keeps per target.

- **Restore**:

  - Takes a destination parent descriptor.
  - Do every check (lock, complete record, hash read through the descriptor later fed to tar, headers, destination absent) BEFORE staging is created.
  - The lead's brief says restore cleans its own staging directory. Do it through descriptors on the inode it created, and list each unlink or rmdir in the pin test.
  - Derive the layout from the record and the headers, and refuse when they disagree:
    - `.` member: a directory;
    - `./.sweeping-<name>`: a file or batch;
    - a P6 `name/...`.

- **Adopt (Task 3.7)**:

  - A P6 archive in the store may be gzip, with `name/...` members. Restore must round-trip it under test, or adoption is not offered.
  - Sniff magic bytes in a shared helper. A missing gzip or xz is a refusal, and its test skips.
