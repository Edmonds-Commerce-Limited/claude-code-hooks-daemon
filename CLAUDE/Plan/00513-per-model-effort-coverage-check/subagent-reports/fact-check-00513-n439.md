## Caveats (wording wider than the evidence)

- C1 (claim 5/6): "A model with no entry therefore runs at its own default effort" (PLAN.md Overview) and "every model runs at its own
  default effort" (N439). The vendored docs (remote-docs/code.claude.com/docs/en/settings-reference.md:956-977 and
  remote-docs/docs.claude.com/en/docs/claude-code/model-config.md:611-613, 688) say a top-level `effortLevel` applies as the
  default for models without an entry (a user-file one is ignored by Opus 5.5 and later). So the sentence is exact only when no
  top-level `effortLevel` is present. N439's scope is "no entries anywhere" and the check's pin logic already covers the project
  and local top-level key, so the effect is small: say "absent a top-level effortLevel" if wanting exactness.
- C2: N439 says "daemon 3.68.0". The repo is at 3.69.0 (pyproject.toml:7). It is the reporter's version, so this is not a claim
  about the tree.
