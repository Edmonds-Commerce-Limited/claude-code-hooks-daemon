Takeaway: I1 and I2 are both live on shipped code.

```

ALLOW | 'curl https://example.com/x -o ../../../tmp/x.sh'
ALLOW | 'wget https://example.com/x -O ../../../tmp/x.sh'
ALLOW | 'mkdir -p ../../../tmp/newdir'
ALLOW | 'tar -cf ../../../tmp/a.tar src'
ALLOW | 'rsync -a src/ ../../../tmp/dest/'
ALLOW | 'cp README.md /tmp/'
```
