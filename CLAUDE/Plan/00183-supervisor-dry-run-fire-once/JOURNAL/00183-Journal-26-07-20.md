## 19:12 · finding · — — root cause of the dry-run loop

User: "when supervisor is in dry run mode - it will loop" (long paste of
alternating `would send [esc]` / `compact suggestion fired` markers, each drawing
a `STOPPING BECAUSE` reply). Follow-up spec: "dry run — it can only fire once per
session — once only."

Traced in `.claude/ccy/claude-supervise.py`: `CompactStateMachine` is pure and
identical in dry-run and armed modes. Armed `WOULD_COMPACT` injects a real
`/compact` that actually compacts → episode RESOLVES. Dry-run injects a marker
that (a) is Enter-submitted (`submit=True` for all but the armed raw ESC) so it
lands as a real prompt that wakes the agent, and (b) never compacts, so context
stays red and the machine cycles `MONITOR → WOULD_COMPACT → AWAIT → WOULD_ESCAPE×5
→ MONITOR → …` up to `max_injections=20`. Failsafe recovery cron `e626acaa`.
