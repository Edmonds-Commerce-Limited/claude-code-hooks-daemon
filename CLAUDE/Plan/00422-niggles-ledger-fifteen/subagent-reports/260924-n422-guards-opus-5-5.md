## N29 — `write_clobber_guard` denied a rewrite of a file the session created

**Root cause.** `matches()` returned True only for a `Read` or for a `Write`
that would clobber. The chain calls `handle()` only when `matches()` is True.
The line in `handle()` that recorded an allowed `Write` sat under
`if not self.matches(...)`, so the daemon never ran it. A file the session
created with `Write` stayed unknown, and the next `Write` to it was denied.
It was not a session-identity or compaction problem. The unit test for the
promise called `handle()` directly, bypassing the gate, and passed.

**Fix.** `matches()` is True for every `Read`, `Edit` and `Write` that
carries a path. `handle()` records every allowed call and denies only a
`Write` that would replace an existing file the session does not know. A
denied `Write` is not recorded. Paths are normalised with `os.path.normpath`,
so `/a/b/../c` and `/a/c` are one record. Knowledge stays per session.

**Trade-off kept.** The record is taken at PreToolUse, as `Read` already was,
not at PostToolUse. A `Write` that a later-priority handler denies is still
recorded. That matters only if another actor then creates the file at the same
path. A PostToolUse recorder needs a second handler that shares state; the
ledger's candidate remedy suggested one if this is ever wanted.

**Defence (DBF).** The class: work in `handle()` under
`if not self.matches(...)`, which only a direct test call reaches. It is
caught by `scripts/qa/check_unreachable_handle_branch.py`, an AST rule wired
into `llm_qa.py` (`unreachable_handle_branch`) and `run_all.sh` (step 31).
Sweep: 8 such branches in `src/`. 7 are bare `return`s and 1 is the
originating instance; `.claude/project-handlers/` has none. The detector was
committed red first.

**Tests.** `tests/unit/handlers/pre_tool_use/test_write_clobber_guard_dispatch.py`
covers:

- Write-then-Write and Edit-then-Write in the same session: allowed.
- The same after another session's Write or Edit: denied.
- A denied clobber: not recorded.
- A `../` spelling of the same path: one file.

Every case goes through the matches-then-handle gate. The two existing suites
now judge decisions through that gate too; their four matches-means-deny
assertions encoded the defect. `tests/unit/scripts/test_unreachable_handle_branch_checker.py`
covers the detector.

## N25 — a shell reserved word read as the command

**Root cause.** Splitting `for f in a b; do grep x "$f" | head; done` on `;`
leaves ` do grep x "$f"`. `pipe_blocker._extract_producer` took that segment
whole, so the whitelist, anchored at `^grep`, missed. The unknown-command
template then offered `^do\b`.

**Audit** (Explore sweep, then each site probed through the worktree venv).
Besides `pipe_blocker`, 12 sites gave a different verdict behind a reserved
word:

- **Bypasses**:
  - `staged_lint_gate`
  - `merge_scope`, which feeds `merge_qa_report` and `daemon_sync_after_merge`
  - `verification_result_gate`, which feeds `bash_safe_mode`'s mutator scope
  - `compile_command_name_pattern`, used by `issue_filing_gate`,
    `quarantine_artefact_read_guard` and `command_hints`
  - `sed_blocker`
  - `worktree_file_copy`
  - `project_containment`
  - `bash_file_writes`, which feeds `plan_journal_guard`
- **False positives**:
  - `shell_segmentation._segment_command_word` (heredoc in a loop body)
  - `_segment_binary` (commit message inside an `if`)
  - `bash_flags` (`{ set -euo pipefail; }`)
  - `budget_exhaustion_detector`
  - both `secret_file_matching` exemption sites
- **Both directions**: `reference_repo_freshness`.
- **No effect**: sites with unanchored patterns, such as `destructive_git`,
  `git_stash`, `curl_pipe_shell` and `sudo_pip`. The full table is in the
  audit report, which the daemon saved outside git.

**Fix.** One primitive lives in `utils/command_evasion`:

- `SHELL_RESERVED_COMMAND_PREFIXES`: `do then else elif if while until ! { time`.
- `RESERVED_WORD_PREFIX`, which also accepts `time -p`.
- `COMMAND_POSITION`, which is `^\s*` plus the prefix plus `ENV_PREFIX`.
- `strip_reserved_word_prefix()`.

`(` is deliberately excluded: it is an operator, and a subshell's `set` does
not persist. The sites use the primitive as follows:

- The anchored patterns take `COMMAND_POSITION` or `RESERVED_WORD_PREFIX`.
- The first-word readers call `strip_reserved_word_prefix` first.
- `bash_flags` accepts only `{`, `!` and `time` before `set`, because a `set`
  behind `then`, `do` or `else` may never run.
- `pipe_blocker` handles a pipe fed by a whole compound command
  (`...; done | tail`, `fi`, `esac`, `}`) with its own deny. That deny names
  no whitelist line and says to move the pipe into the body or capture the
  whole output. The reserved-word set also backstops that routing, so a
  whitelist suggestion can never name one.

**Not fixed, for the owner.** `secret_file_matching.is_exempt_invocation` and
`_is_encrypted_target_reader` withhold their exemption for `time cat …` and
`! cat …`. That is the safe direction, and those functions are a deliberate
fail-closed allowlist (Plans 00272 and 00459), so widening them is the owner's
call. They have no declared row.

**Defence (DBF).** 9 rows were added to `scripts/qa/declared-invariant-pairs.yaml`:

- 6 `reaches: strip_reserved_word_prefix`.
- 3 `interpolates` of `COMMAND_POSITION` or `RESERVED_WORD_PREFIX`.

They were committed red first (`6be0ae57`, 9 violations) and are green after
the fix (17 rows hold). The `319cdd35` commit message says 10 rows; the true
count is 9. The instance is recorded in `CLAUDE/Security/AsymmetricSiblingProtection.md`.
Blind spot: a new site that reads a first word is not covered until someone
adds a row for it.

## Worth knowing at integration

- The N25 fix makes several guards fire on commands inside loop and `if`
  bodies that they missed before. That is intended, and release note 20 says
  so.
- `pipe_blocker` still denies `(grep x f) | head`. Its producer is
  `(grep x f)`, which the `^grep\b` whitelist does not match. That is a
  subshell-opener false positive of the same family. I verified it and left it
  out of scope, because `(` is excluded from the shared primitive.
