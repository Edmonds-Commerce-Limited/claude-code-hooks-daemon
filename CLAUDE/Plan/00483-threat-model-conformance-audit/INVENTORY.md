## secret_file_guard

Summary: PreToolUse SAFETY+BLOCKING terminal guard (H:1204-1250, priority SECRET_FILE_GUARD). Denies (1) Read/Write/Edit/NotebookEdit/Grep whose path matches a protected glob or its realpath (H:1448-1477), (2) any Bash command whose text mentions a protected path, or a glob that could expand to one (H:1385-1446), (3) Write/Edit of script-like content that mentions one (H:1479-1483, 1494-1608). Default globs `*.secret*`, `.vault-pass*`, `*.vault-password`, `*vault_pass*`, `id_rsa`, `id_ed25519` (SFM:76-83). Every raise in evaluation is filed as a deny (H:1340-1362).

### In-scope false positives

All verified with `bin/hooks-daemon probe PreToolUse`. Commands that mention a protected name literally are built from files, never typed in this report's Bash calls.

FP-1 (cause: SE:383-386 + 823-833 + 857-872, out-of-scope branch, limb 2). A `${...}` holding a quote, then any later `{` (awk program, JSON body, `find -exec {}`) fails closed as unreadable.

- `set -euo pipefail; x=${PREFIX:-"/usr"}; awk '{print $1}' f` -> deny R-SECRET-COMMAND-UNREADABLE (probe c#9)
- `set -euo pipefail; x=${PREFIX:-"/usr"}; find . -exec ls {} \;` -> deny UNREADABLE (c#8)
- `set -euo pipefail; echo ${x#"pre"}; awk '{print $1}' f` -> deny UNREADABLE (c#13); `echo ${x//\"/}; awk ...` (c#14); `echo "${x:-'y'}"; awk ...` (c#10)
- `echo ${x:-'y'}; echo '{a}'` -> deny UNREADABLE (b#5); `echo "${arr[@]:-"z"}" && echo '{x}'` (b#40)
- authored: Write of a.sh `x=${y:-"z"}` + `awk '{print $1}' f` -> deny R-SECRET-COMMAND-UNREADABLE (f#3); j.sh `echo "${x:-'y'}" | jq '{a:1}'` (f#11)
- controls that allow: `${x:-y}` + awk (c#12), `${x:-"y"}` alone (c#11, c#19), `${x/a/b}`, `${#x}`, `${x:-$(date)}` + awk (c#15-17)

FP-2 (cause: SEG:1412-1418, 2335-2885 rebinding prefix, out-of-scope branch, limbs 1+2). An ordinary statement before a commit-message heredoc cancels the heredoc blanking, so a message that names a protected file is denied. Message `fix <protected-name>` via `git commit -F - <<'EOF'`:

- allowed with no prior statement (e#6) and after `x=$(date)`, `for`, `read`, `[ -f x ]`, `export FOO=bar`, `declare`, `unset`, `VAR=/x` (e#8, e#11, e#12, g#6, g#11-13, g#15-18)
- denied R-SECRET-BASH-MENTION after: `cd "$DIR"` (g#1), `cd "$(git rev-parse --show-toplevel)"` (g#2), `n=$(( n + 1 ))` (g#3), `shopt -s nullglob` (g#4), `trap 'rm -f t' EXIT` (g#5), `export PATH="$HOME/bin:$PATH"` (g#7, e#13), `eval "$(ssh-agent)"` (g#8), `. venv/bin/activate` (g#9), `source ./env.sh` (e#10), `cd ~` (g#10), `exec 3>&1` (g#14), `f() { echo hi; }` (e#9), `alias g=git` (e#14)
- Only the first alias/function/PATH/`source`/`eval` rows are limb-2 shapes; the rest are ordinary and are caught by the same predicate.
