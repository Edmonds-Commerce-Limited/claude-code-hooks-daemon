# Task 3.2 X-1: narrow the heredoc rebinding check (sonnet)

Branch: worktree-p483-x1-rebind-heredoc

## Change

`src/claude_code_hooks_daemon/utils/shell_segmentation.py`, `_command_may_rebind` family:

- `cd`, `pushd`, `popd` never count as rebinding (was: any non-literal target, `~`, extra
  options, stack rotation, `popd`). `_directory_change_may_rebind` and its constants deleted.
- `source` and `.` never count (limb 1: the file's text is not shown).
- `export`/`declare`/... `NAME=<non-literal value>` counts only when NAME is a special
  variable (`_names_may_rebind`); `export X=$Y`, `export X=$(date)` no longer count.
- Still counting: alias/function definitions, `PATH` and the other special-name bindings,
  `eval`, `command`, `builtin`, `hash`, `printf -v`, arithmetic, `set` off its inert options,
  a non-plain head, and so on (untouched).
