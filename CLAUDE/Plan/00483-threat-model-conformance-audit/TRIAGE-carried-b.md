## IN-SCOPE defects

Entries: N124, N130, N136, N143, N144, N152, N153, N184, N220, N221, N249.

### D1: a Bash search over a tree holding a protected file is not judged (N143, N144, N152, N153, with N220 as the glob twin)

On main the Bash route is a text scan of the words. Only the Grep tool checks directory
contents. Reproduction, cwd `fx/t1` (holds `dir/key.<secret-suffix>`):
`grep -r x dir`, `grep -r x .`, `cat dir/*`, `find . | xargs rg x`, `git grep needle` (tracked
file), `bash -c 'grep -r x .'`. All allowed. Outcome at risk: protected content disclosure. Same
for DETAIL artefacts in the quarantine guard (`grep -r x .` in a dir with one). The ruling keeps
protection "against every ORDINARY read route". Cost to watch: this repo holds a protected word
list, so a naive walk would deny every `grep -r` here. The dropped branch used git's view
(tracked and unignored files) to avoid that, which brought N150 and N151 with it. N150 and N151
are not separate defects on main.

### D2: Grep directory scan fails open past 5000 files (N130)

Reproduction: Grep tool, `path=/tmp/p483fx4`, 5500 files at the top level and
`zdeep/key.<secret-suffix>`. Verdict allow. With the 5500 files removed, deny. At risk: protected
content disclosure. The ruling's "a guard that cannot read what it judges still fails closed"
applies: past the cap the guard should deny, not answer none.

### D3: directory and absolute-path patterns are matched on the spelling only (N184, N221)

Reproduction (matcher called directly, pattern `<T>/vault/**`, project pattern shape):
`cat r.md` with cwd `<T>/vault`; `cd vault && cat r.md`; `cat <T>/x/../vault/r.md`. All return
no match. A command that spells the full path matches. The default patterns are name-based, so
this only bites projects that configure directory or absolute-path patterns. At risk: protected
content disclosure.

### N136: dotted module name read as a path

Reproduction: `python -m claude_code_hooks_daemon.utils.secret_meta --help` denied; so is any
`-c "import pkg.secret_x"`. A client with a module called `secret_*` cannot run or import it.
Ordinary command wrongly denied.

### N124 residual and the regex-text class

Reproduction: `grep -n 'foo\.secret' f` denied; `find . -regex '.*decision:.*'` denied;
`python3 -c "import re; re.findall(r'probe:.*decision:', 'x')"` denied. grep, rg and awk are
exempted for simple patterns, but an escaped dot or an alternation defeats the exemption and
other tools have none. Ordinary command wrongly denied.

### N249: double-quoted one-liner with escaped inner quotes

Reproduction: `python3 -c "print(open(\"id_rsa\").read())"` is allowed; with single quotes the
same code is denied. At risk: protected content disclosure. The body is literal and visible, so
it is in scope.
