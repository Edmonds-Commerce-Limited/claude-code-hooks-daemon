## 09:00 · finding · P1 — the mechanism, observed

Filed as a follow-on to Plan 00336 Task 4.3, which fixed the drifted file and
deliberately left the reason it went unnoticed to this plan.

```
$ git check-ignore -v .claude/skills/hooks-daemon/SKILL.md
.claude/.gitignore:3:hooks-daemon/	.claude/skills/hooks-daemon/SKILL.md
```

`.claude/.gitignore` line 3 sits under the comment "Exclude the cloned daemon
repository (users install it themselves)" — the intended target is
`.claude/hooks-daemon/`. Without a leading slash git matches the pattern at any
depth, so the deployed skill tree is swept up with it.

The asymmetry is what makes it a design question rather than a typo: the other
deployed skill, `.claude/skills/docs-qa/`, IS tracked, and its own drift
surfaced immediately when `deploy_skills` ran during 00336. Two adjacent
deployed trees, opposite treatment, no decision behind it.
