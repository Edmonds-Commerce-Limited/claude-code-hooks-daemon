**One implementation.** `plan_qa/checks/stats_arithmetic.py` holds the patterns, the pure `stats_arithmetic_disagreements(text)` function, which returns `(line, message)` records with the line number inside the message, and the remediation text. `scripts/qa/check_repo_hygiene.py` keeps its `plan_stats_arithmetic(root)` only as a thin adapter, and imports `CHECK_ID` and `REMEDIATION`. `test_there_is_exactly_one_implementation` fails if the folderless-clause regex appears in any other `src/` or `scripts/` file.

**Registration.** The check carries `sins=("B5",)`, the statistics-drift sin that `stats-recount` also carries.

- **COMMIT** blocks only when the commit stages the plan index AND the disagreement is not already present in HEAD's index (`commit_scoped_level`). A commit that does not touch the index gets an advisory, so inherited drift cannot trap unrelated commits (Plan 00343's rule).
- **SWEEP** blocks, which puts it in `plan-qa --sweep`.
- **EDIT** is advisory only. Updating the bullet takes more than one edit, so a block would deny the first half of a correct update. This is the same reasoning `index-retention-window` documents for having no EDIT registration at all.
