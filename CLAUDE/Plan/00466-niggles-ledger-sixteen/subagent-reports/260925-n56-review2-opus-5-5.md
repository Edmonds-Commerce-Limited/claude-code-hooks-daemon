Caught, as the brief asked: `getpass.getuser() == "root"`, `os.getuid() == 0`,
a conftest `pytest_runtest_setup` with `if root: pytest.skip`, and
`raise unittest.SkipTest`.

A pattern list will always trail the evasions. A sturdier approach is a runtime
probe alongside the static scan. For example, a session-scoped conftest fixture
or plugin could patch `os.geteuid`, `os.getuid`, `getpass.getuser`,
`pwd.getpwuid` and `os.environ["USER"]` to report a non-root identity, then
assert that the collected and skipped sets do not change compared with the
real root run. Short of that, the detector at least needs a uid-*value* taint:
any name or return value derived from a uid, user or pw call. It also needs to
handle `AnnAssign`/lambda/aliases, `skipUnless`, and conftest hooks.

### B2 (BLOCKER): the detector uses exclusion lists, and one hides a real skip

The brief says the detector "must not use suppressions or exclusion lists".
`test_no_root_conditioned_skips.py:597` has `_EXCLUDED_DIR_NAMES = {"fixtures", "assets", "__fixtures__"}`
(it matches any path component, anywhere). `:605` also excludes the detector
file itself.

pytest does collect `tests/fixtures/**/test_*.py`: `testpaths = ["tests"]`,
and there is no `norecursedirs`. Repro in the HEAD copy:

```
mkdir -p tests/fixtures/evade
# test_evade.py: @pytest.mark.skipif(os.geteuid() == 0, reason="Running as root")
pytest tests/fixtures/evade/test_evade.py -rs
  -> SKIPPED [1] tests/fixtures/evade/test_evade.py:3: Running as root
pytest tests/integration/test_no_root_conditioned_skips.py -k TestTheRepositoryItself
  -> 1180 passed   (detector GREEN)
```

Neither exclusion is needed:

- The detector scans itself clean (`n56r2/selfscan.py` prints
  `self findings: []`).
- Only 2 of the 30 excluded files cannot be parsed:
  `tests/fixtures/plugins/syntax_error_handler.py` and
  `tests/fixtures/project_handlers_error_cases/session_start/syntax_error_handler.py`.

Fix: drop both exclusions and handle `SyntaxError` per file. A file pytest
would never import (not `test_*.py`/`conftest.py` and not imported) may be
passed with a logged note. An unparseable `test_*.py`/`conftest.py` must fail.
