## What changed

`tests/integration/test_no_root_conditioned_skips.py` is rewritten to key on
data flow instead of literal call names, per the coordinator's design
direction:

- Identity-source classification (`_identity_kind`) resolves
  `geteuid`/`getuid`/`getegid`/`getgid`/`getresuid`/`getresgid`,
  `getpass.getuser`, `pwd`/`grp` lookups (and their `.pw_name`/`.pw_uid`/
  `.gr_name`/`.gr_gid`/positional-subscript fields), `os.environ`/`os.getenv`
  of `USER`/`LOGNAME`/`HOME`/`SUDO_*`, `Path.home()`/
  `os.path.expanduser("~")`, `os.access(...)` and `<expr>.stat().st_uid`
  through an alias (`from os import geteuid as euid`, `_uid = os.geteuid`),
  a local variable, a module constant (`Assign`/`AnnAssign`), and one level
  of same-module helper (`def` or zero-arg `lambda`, including a
  parameterised helper called with literal args, substituted before
  evaluation).
- `_is_root_expr` flags a condition comparing an identity value to 0/"root"/
  another identity value, a bare truthy/`not`/arithmetic/walrus use, or a
  resolved boolean name/helper, recursing through `BoolOp`/`UnaryOp`/`IfExp`/
  a string condition.
- New `_ifexp_findings` (a `pytest.mark.skip(...) if <root> else ...`
  marker) and `_collection_hook_findings`
  (`pytest_ignore_collect`/`pytest_collection_modifyitems`/
  `pytest_runtest_setup`).
- `_is_unproven_identity_ref`: a cross-module import or class attribute this
  scan cannot resolve is reported (not silently passed) when its own
  spelling names root/uid/gid/privilege/sudo — restricted to
  SCREAMING_SNAKE/PascalCase-looking names so it doesn't fire on this
  detector's own snake_case identifiers during the self-scan.
- B2: dropped both exclusions (`fixtures`/`assets`/`__fixtures__` directory
  names, and the detector's own file). `_test_sources()` now scans
  everything under `tests/`; a file that fails to parse only fails the test
  when pytest would import it (`test_*.py`/`conftest.py`); otherwise it's a
  `warnings.warn` and treated as clean.

All 41 of review 2's hand-written evasion shapes were folded into
`_SHOULD_FIND` as a parametrised RED corpus (70 shapes total with review 1's
originals); all pass. `_SHOULD_NOT_FIND` gained 3 new false-positive guards

`chmod` shell function that fails for exactly one hook file (same technique

secondary guard; its docstring no longer claims root can be used to force a
