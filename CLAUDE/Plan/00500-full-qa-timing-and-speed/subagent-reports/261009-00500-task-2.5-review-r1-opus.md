## What is sound

- **Unknown paths widen.** Non-Python files and Python outside `src/`, `scripts/` and
  `tests/` are whole-suite. So are an empty reach and a reach that spans every shard.
- **The root conftest widens.** A reach through it returns None, which means whole-suite.
- **Bad declarations fail loudly.** A YAML or parse error, an unreadable file, an unknown
  key, a floor naming an undeclared shard (which also covers a shard rename), and an empty
  `shards:` all raise `ShardError`, which becomes an `EXIT_OPERATIONAL` failure report.
- **Nothing runs twice.** A remainder shard expands to explicit files.
- **Deleted files are unchanged.** `deleted-but-referenced` behaves as before.
