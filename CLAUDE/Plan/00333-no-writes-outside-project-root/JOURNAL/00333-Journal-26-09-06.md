> **Entry grammar** — append new entries at the BOTTOM; NEVER edit earlier

>   one-line takeaway above the fence.
> - End a working session with a `handoff` entry so the next agent's entry
>   point is the last entry of the newest day-file.

## 13:58 · finding · P4 — a claim that did not survive checking

Reported that the 225 captures came from following `pipe_blocker`'s own snippet
(`TEMP_FILE="/tmp/output_$$.txt"`), so changing that one string would have
prevented ~99.6% of the residue. Checked it: **zero** files match
`output_<pid>.txt`, **zero** match `echd-capture`'s `command-output-*` stem —
every name is ad-hoc (`bl.txt`, `dq.txt`, `cli2.txt`).

The snippet was never being pasted. What the daemon supplied was the
*destination convention*, not the command, so the one-liner is habit-shaping
rather than a structural interception. Hence Phase 2 carries the enforcement and
Phase 4 is guidance hygiene — the reverse of the original pitch.

Incidental positive: no `command-output-*` file exists in `/tmp`, so
`echd-capture` never took its `/tmp` fallback. The convention holds where it is
implemented in code and fails only where it is left to agent judgement.
