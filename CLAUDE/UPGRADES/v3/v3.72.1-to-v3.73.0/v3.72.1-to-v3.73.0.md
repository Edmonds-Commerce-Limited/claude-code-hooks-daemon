# Upgrade Guide: v3.72.1 to v3.73.0

## Summary

- **Breaking changes:** No. This release ships no config-changes manifest, so the pre-deploy gate lists nothing under `READ THIS FIRST` for it.
- **Config migration required:** No.
- **Pre-upgrade tasks:** none. **Post-upgrade tasks:** none. **Truth-changes:** `CLAUDE/UPGRADES/truth-changes/v3.73.0.yaml` (the `gh` view `--json` form; per-call recovery bundles).

## What changes for an existing project

- **Recovery bundles accumulate.** `delete-branch` and `branch-sweep --clean` write one bundle per call under `untracked/deleted-branches/` and print one restore line per deleted branch. An existing `untracked/deleted-branches.bundle` is left in place; it still holds the last branch deleted before the upgrade.
- **`branch-sweep --clean --remote` is new.** It deletes merged branches on `branches.remote` as well, behind the same proof the remote-delete guard applies, with a lease on each tip.
- **`branch-sweep --clean` leaves running agents' worktrees and branches alone** (a `running` work-queue record, a worktree under `.claude/worktrees/`, or a `locked` worktree).
- **Branch containment sees remote refs outside `refs/heads`** (for example `refs/archive/<name>`) through one bounded `git ls-remote` made by the explicit commands `branch-sweep` and `delete-branch`.
- **The ccy supervisor finds `hooks-screen` by host architecture** (x86_64/amd64 and aarch64/arm64, musl). A client that excluded the deployed supervisor from its QA because of the pinned triple can drop that exclude.
- **The `gh issue view` / `gh pr view` guards suggest `--json title,body,state,comments`**, which returns the body as well as the comments.
- **`lsp_enforcement` no longer denies a grep over extensionless files** no language server serves.

## Steps

Follow the commands in `RELEASES/v3.73.0.md`, "Upgrading Existing Installations". No configuration edit is needed.

## Verification

```bash
.claude/hooks-daemon/bin/hooks-daemon restart
.claude/hooks-daemon/bin/hooks-daemon status
.claude/hooks-daemon/bin/hooks-daemon config-validate
```

## Rollback

Restore the backup of `.claude/hooks-daemon.yaml`, then upgrade to the previous tag with the same procedure and `v3.72.1` as the target.
