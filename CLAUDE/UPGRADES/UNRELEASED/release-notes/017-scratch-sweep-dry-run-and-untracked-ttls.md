# Callout: a scratch sweep that archives before it removes, with a TTL per untracked directory

**Plan**: 00627
**Audience**: everyone

`hooks-daemon scratch-sweep` judges every entry under `untracked/scratch/` (LIVE, STUCK, PROTECTED, REFERENCED, DISPOSABLE or UNCERTAIN). Run plainly it is a dry run and changes nothing. With `--apply` it archives and then removes every due DISPOSABLE or UNCERTAIN entry, and expires archives past retention, but only after a human types `apply <root>` at a terminal (stdin and stdout both a TTY); an agent or a pipe is refused and nothing changes. An archived entry comes back with `scratch-sweep restore ID`, and `scratch-sweep keep ID --reason R` holds one. An entry a tracked file names (`untracked/scratch/<entry>...` on HEAD, the default branch, an unmerged local branch or an uncommitted tracked edit) is REFERENCED, with the first file and line in the reason; when that search fails the entry is STUCK, never DISPOSABLE. A repository inside an entry is classified: a registered worktree, or a related clone with unpushed, stashed or dirty work, makes the entry PROTECTED; a standalone repository (no remote, no shared history) is DISPOSABLE, while files beside it are judged on their own. `--root` accepts only a directory inside the project's `untracked/` that is not inside a repository. How long an entry may sit before it is due is set per directory under `untracked/` by the new `scratch.untracked_ttl` map (`scratch: 24h` and `repos: "*"` by default; `"*"` means never cleared, and must be quoted in YAML). `untracked/repos`, every reference-repository root and the archive store are never swept whatever the map says, and a directory the map does not name is never swept unless you set `scratch.untracked_default_ttl`.
