# Callout: `git checkout <commit> <path>`, `git checkout <path>` and xargs-fed checkouts are judged

**Plan**: 00474
**Audience**: everyone

R-GIT-CHECKOUT-DISCARD keyed on the `--` separator, so `git checkout <commit> <path>` (which restores the path from the commit exactly as the dashed form does) and `git checkout <path>` (which restores it from the index) were allowed even over unsaved local changes, and so was `... | xargs git checkout <commit> --`, whose paths arrive on stdin. Git reads the undashed form by resolving the first operand, and the guard now reads it the same way. `git checkout <commit> <paths>` gets the SAME allowance as `git checkout <commit> -- <paths>` when the first operand is one literal revision that resolves to a tree and names no path in the working tree or the index; when it is also a path, git refuses it as ambiguous, and when it does not resolve, git restores every operand from the index, so both are denied. A one-operand `git checkout <name>` stays allowed when `<name>` is a commit (a branch switch, even when a file has the same name) or names no path at all (the remote-branch shortcut); when it names a path it is a restore from the index and is denied, as `git checkout -- <path>` is. A checkout with an option a branch switch does not use (`-p`, `--ours`, `--no-overlay`, `--pathspec-from-file`, an abbreviation) is judged as a path checkout and denied. A `git checkout` or `git restore` run by `xargs`, `parallel`, `find`/`fd` or a prefix that is not a plain wrapper (`sudo`, `env`, `timeout`, `nice`, ...), or fed by a pipe or an input redirect, is denied whatever its form, including `echo main | xargs git checkout`. A one-operand checkout whose repository cannot be placed (an assignment, a global option other than `-C`, an unresolvable `cd`) is denied too. Also: `git checkout-index -f` (and `-af`, `--force`), which overwrites worktree files from the index and matched no rule, is now denied under R-GIT-CHECKOUT-FORCE; without `-f` git refuses to overwrite an existing file and it stays allowed.
