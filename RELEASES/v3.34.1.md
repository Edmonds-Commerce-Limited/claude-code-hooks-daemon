# v3.34.1 — ccy supervisor: correct sidecar path + empty-input-box injection guard

**Release date**: 2026-07-10
**Type**: PATCH release

## Summary

v3.34.1 fixes two High-severity bugs in the Plan 00135 PTY supervisor
(`.claude/ccy/claude-supervise.py`), both surfaced once v3.34.0 made the
supervisor actually deploy, arm, and run in client projects. Without them the
supervisor either never observed context (so it never fired `/compact`) or, when
it did fire, could corrupt the human's in-progress input. No breaking changes.

## Highlights

- **Bug A — sidecar path (compact trigger was inert in every client).** The
  daemon writes the context sidecar install-mode-aware to
  `daemon_untracked_dir()/context-sidecar`
  (`{project}/.claude/hooks-daemon/untracked/context-sidecar` in a normal client;
  `{project}/untracked/context-sidecar` in self-install), but the supervisor
  hardcoded the self-install layout — so in every real client install it polled a
  directory the daemon never wrote and never advanced past "no reading". The
  supervisor now mirrors the daemon's own install-mode detection and reads the
  correct directory in both modes.
- **Bug B — empty-input-box injection guard.** The supervisor could paste its
  injection into a non-empty input box the human had partially typed into and
  submit the corrupted mix. It now tracks the human input line from forwarded
  stdin and only ever injects into an empty box; a non-empty box defers the tick
  (and logs it) and retries when the box is empty again.

## Changes

### Fixed

- **Supervisor polled the wrong context-sidecar directory in normal client
  installs (Plan 00149, Bug A)** — `_default_sidecar_dir()` now mirrors the
  daemon's `ProjectContext` install-mode detection (self-install iff
  `{project}/src/claude_code_hooks_daemon` exists) and resolves the same
  directory the daemon writes to. Stdlib-only; stable at startup before any
  sidecar exists.
- **Supervisor could inject into a non-empty input box and submit it (Plan 00149,
  Bug B)** — a new `HumanInputLine` model, fed from the forwarded operator stdin,
  gates every injection path (armed `/compact`, `continue`, dry-run marker) on
  the box being empty. Supervisor-injected keystrokes bypass the recorder so the
  bot never marks the box non-empty; the model is conservative so a false
  "non-empty" only defers a tick while the corrupting false "empty" is avoided.

No breaking changes — no upgrade guide required. No new config keys.

## Upgrade

```
Use the hooks-daemon upgrade skill (Skill tool: skill=hooks-daemon, args=upgrade).
```

The upgrade refreshes `.claude/ccy/claude-supervise.py` in any ccy project (via
`ccy.deploy_supervisor`). No config migration is required. After upgrading, a ccy
project's supervisor will observe the daemon's real sidecar directory and only
inject into an empty input box.

## Installation

### New Installations

```bash
mkdir -p .claude && cd .claude
git clone https://github.com/Edmonds-Commerce-Limited/claude-code-hooks-daemon.git hooks-daemon
cd hooks-daemon
git fetch --tags && git checkout v3.34.1
python3 -m venv untracked/venv
untracked/venv/bin/pip install -e .
untracked/venv/bin/python install.py
cd ../..
```

### Upgrading Existing Installations

```bash
cd .claude/hooks-daemon
git fetch --tags
git checkout v3.34.1
untracked/venv/bin/pip install -e .
untracked/venv/bin/python -m claude_code_hooks_daemon.daemon.cli restart
```
