# v3.58.1 — Secret-Guard False Positive, Pipe-Blocker Attribution, and Config Validation Fixes

**Release Date:** 2026-09-01
**Type:** Patch Release

## Summary

This release fixes a `secret_file_guard` false positive that denied legitimate
edits containing incomplete bracket expressions (e.g. a Python list literal
matching a protected-path glob like `*vault_pass*`), corrects `pipe_blocker`
producer attribution for pipes inside quoted arguments, and surfaces an
absolute `secret_word_list_path` as a visible degraded-status line instead of
a silent log-only warning. It also turns a misplaced `{REPO_ROOT}` token in
plugin/project-handler paths into a named config validation error instead of
a startup traceback. No breaking changes.

## Highlights

- **`secret_file_guard` false positive fixed** — glob-shape detection now
  requires a complete bracket expression, so content like
  `[pass_result, fail_result]` no longer matches protected-path globs such as
  `*vault_pass*`.
- **`pipe_blocker` producer attribution fixed** for pipes inside quoted
  arguments — the block reason now names the real producer with a runnable
  remediation.
- **Security observability improved** — an absolute `secret_word_list_path`
  now shows as a degraded-status line on `hooks-daemon status`/`check`,
  instead of silently disabling secret-term blocking with only a log warning.
- **`{REPO_ROOT}` misplacement is a named config validation error**, not a
  startup traceback.

## Installation

### New Installations

```bash
mkdir -p .claude
git clone -b v3.58.1 https://github.com/Edmonds-Commerce-Limited/claude-code-hooks-daemon.git .claude/hooks-daemon

# The installer builds the fingerprint-keyed venv, installs the package and
# starts the daemon. Never hand-build a venv — the resolver refuses the
# retired pre-v3.7.0 layout.
bash .claude/hooks-daemon/scripts/install_version.sh "$PWD" "$PWD/.claude/hooks-daemon"
```

### Upgrading Existing Installations

```bash
cp .claude/hooks-daemon.yaml .claude/hooks-daemon.yaml.backup
git -C .claude/hooks-daemon fetch --tags

# Rebuilds the venv and reinstalls the package for the target version.
bash .claude/hooks-daemon/scripts/upgrade_version.sh \
  "$PWD" "$PWD/.claude/hooks-daemon" "v3.58.1"

.claude/hooks-daemon/bin/hooks-daemon restart
```
