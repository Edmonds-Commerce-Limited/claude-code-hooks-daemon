## Summary

v3.18.1 is a single-fix patch. `scripts/upgrade.sh` now calls `check-truth-changes --from <from> --to <to>` after a successful upgrade and prints a prominent "Project-doc reconciliation" summary block before the `UPGRADE_METADATA` output. Agents running the bare script directly — rather than following `upgrade.md` step 4 — therefore still see which project docs need reconciling. No daemon package code, handler, or configuration changed.

## Upgrade

```bash

```

No configuration changes required. This release is fully backwards-compatible. The fix is delivered to existing installations via the Plan 00109 thin-shim — `upgrade.sh` fetches and execs the canonical script from `main` HEAD, so existing installs receive this change automatically on the next upgrade run without requiring a manual `git checkout`.

## Installation

### New Installations

```bash
mkdir -p .claude && cd .claude
git clone https://github.com/Edmonds-Commerce-Limited/claude-code-hooks-daemon.git hooks-daemon
cd hooks-daemon
git fetch --tags && git checkout v3.18.1
python3 -m venv untracked/venv
untracked/venv/bin/pip install -e .
untracked/venv/bin/python install.py
cd ../..
```

### Upgrading Existing Installations

```bash
cd .claude/hooks-daemon
git fetch --tags
git checkout v3.18.1
untracked/venv/bin/pip install -e .
untracked/venv/bin/python -m claude_code_hooks_daemon.daemon.cli restart
```
