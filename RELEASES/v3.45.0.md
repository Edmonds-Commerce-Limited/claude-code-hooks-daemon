# Release v3.45.0 - Stop Hook False Daemon-Down Fix

**Release Date:** 2026-07-20
**Type:** Minor Release

## Summary

This release fixes a false "Hooks daemon not running" `decision:block` on
long-running Claude Code sessions (Plan 00177). Two independent root causes
were identified and fixed: an honest, configurable socket timeout with
fail-open behaviour on Stop/SubagentStop, and a bounded tail read that
eliminates repeated whole-file transcript parsing in the Stop hot path.

## Highlights

- **`CLAUDE_HOOKS_SOCKET_TIMEOUT` env var**: configurable socket read
  timeout (default `30.0`) for the bash hook forwarder (`init.sh`).
- **Fail-open on Stop/SubagentStop socket timeout**: a `socket.timeout`
  talking to the daemon is now reported honestly ("daemon is ALIVE, do NOT
  restart") and returns `{}` instead of a false `decision:block`.
- **`TranscriptReader.load_tail()`**: a new bounded tail read (default cap
  1 MiB) replaces whole-file transcript parsing in the Stop hot path.
- **Massive latency win on large transcripts**: a 150 MB transcript Stop
  probe went from 30s (timeout) to 0.72s.

## Changes

### Added

- `CLAUDE_HOOKS_SOCKET_TIMEOUT` env var (default `30.0`) controlling the
  socket read timeout in `init.sh`.
- `TranscriptReader.load_tail()` bounded tail read (default cap
  `_DEFAULT_TAIL_BYTES` = 1 MiB).

### Changed

- Stop/SubagentStop now fail OPEN on a socket timeout with honest
  "daemon is ALIVE, do NOT restart" messaging instead of a false
  `decision:block` "Hooks daemon not running".
- `auto_continue_stop` now uses the bounded tail read instead of
  whole-file transcript parsing (was up to ~9x full-file parses per Stop
  dispatch).

### Fixed

- False `decision:block` "Hooks daemon not running" on long sessions,
  caused by (1) a flat 30s socket timeout indistinguishable from a dead
  daemon, and (2) repeated whole-file transcript parsing exceeding the
  client's response budget on large transcripts.

## Installation

### New Installations

```bash
cd .claude
git clone -b v3.45.0 https://github.com/Edmonds-Commerce-Limited/claude-code-hooks-daemon.git hooks-daemon
cd hooks-daemon
python3 -m venv untracked/venv
untracked/venv/bin/pip install -e .
untracked/venv/bin/python install.py
```

### Upgrading Existing Installations

```bash
cd .claude/hooks-daemon
git fetch --tags
git checkout v3.45.0
untracked/venv/bin/pip install -e .
untracked/venv/bin/python -m claude_code_hooks_daemon.daemon.cli restart
```
