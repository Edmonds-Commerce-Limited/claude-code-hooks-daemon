# v3.28.0 — Minor: release-notes CLI subcommand + skill route

**Release date**: 2026-06-24
**Type**: MINOR release

## Summary

v3.28.0 ships a `release-notes` CLI subcommand and a `/hooks-daemon release-notes`
skill route (Plan 00141). Any Claude Code session can now read the bundled per-version
release notes on demand — by installed version, by explicit version, by range, or as a
list — in markdown or JSON format, without leaving the session or navigating the
filesystem.

## Highlights

- **`release-notes` CLI subcommand** — `$PYTHON -m claude_code_hooks_daemon.daemon.cli release-notes` reads `RELEASES/vX.Y.Z.md` files bundled with the daemon. Defaults to
  the installed version (`--latest`). Supports `--version X.Y.Z`, `--from A --to B`
  (range; `--from` exclusive, `--to` inclusive), `--list` (enumerate available
  versions), and `--format markdown|json`.
- **`/hooks-daemon release-notes` skill route** — The `/hooks-daemon` skill now exposes
  the subcommand so any agent can run `/hooks-daemon release-notes` (or
  `release-notes --latest`, `release-notes --list`, `release-notes --version 3.27.0`,
  etc.) without knowing the Python path or the `RELEASES/` layout.
- **Pure `install/release_notes.py` module** — Discovery and parsing are isolated in a
  single module, independently testable and reusable by any future CLI command or
  plugin that needs to inspect release history.
- **No breaking changes** — All existing configurations continue to work unchanged.

## Changes

### Added

- **`release-notes` CLI subcommand and `/hooks-daemon release-notes` skill route (Plan
  00141)** — A new `$PYTHON -m claude_code_hooks_daemon.daemon.cli release-notes`
  command reads the per-version `RELEASES/vX.Y.Z.md` files bundled with the daemon and
  prints them in markdown or JSON format. Options: `--latest` (installed version, the
  default), `--version X.Y.Z` (specific version), `--from A --to B` (range; `--from`
  exclusive, `--to` inclusive), `--list` (enumerate all available versions),
  `--format markdown|json`. The pure module
  `install/release_notes.py` handles discovery and parsing; `cmd_release_notes` in
  `daemon/cli.py` wires it into the CLI. The `/hooks-daemon` skill exposes the
  subcommand as `release-notes` so any Claude Code session can run
  `/hooks-daemon release-notes` without needing to know the Python path.

## Usage Examples

```bash
# Show release notes for the installed version (default)
$PYTHON -m claude_code_hooks_daemon.daemon.cli release-notes
$PYTHON -m claude_code_hooks_daemon.daemon.cli release-notes --latest

# Show release notes for a specific version
$PYTHON -m claude_code_hooks_daemon.daemon.cli release-notes --version 3.27.0

# Show release notes for a range (--from exclusive, --to inclusive)
$PYTHON -m claude_code_hooks_daemon.daemon.cli release-notes --from 3.26.0 --to 3.28.0

# List all versions with available release notes
$PYTHON -m claude_code_hooks_daemon.daemon.cli release-notes --list

# Output as JSON (for programmatic use)
$PYTHON -m claude_code_hooks_daemon.daemon.cli release-notes --format json
$PYTHON -m claude_code_hooks_daemon.daemon.cli release-notes --list --format json
```

Via the skill (from any Claude Code session):

```
/hooks-daemon release-notes
/hooks-daemon release-notes --latest
/hooks-daemon release-notes --version 3.27.0
/hooks-daemon release-notes --from 3.26.0 --to 3.28.0
/hooks-daemon release-notes --list
/hooks-daemon release-notes --format json
```
